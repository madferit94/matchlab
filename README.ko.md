# MatchDesk — AI 경기 분석실 에이전트 팀

[English](README.md) | [한국어](README.ko.md)

축구 자료 수집 → 팀 비교 → 화면 → 독립 검증 → 최종 내부 결재를 연결하는 **5인 에이전트 팀**입니다. Agentic AI Fundamentals 제출·포트폴리오를 위한 프로젝트입니다. 현재 버전은 **0.2.1**입니다.

## 현재 구현된 것

에이전트 정의·재사용 스킬·자료 형식 검사·담당/승인 규칙·오프라인 비교 화면을 구현했습니다. 아스널–리즈, 말라가–에스파뇰 대표2경기는 이전10역할 배정으로 실제 수집·분석·검증·결재를 수행했습니다. 이를5인팀 실행으로 바꾸어 기록하지 않습니다. **예측 모델·자동 갱신·예측 API·공개 서비스는 미구현**이며 Claude 실제 실행과 통합5인 재실행은 미검증입니다.

## 에이전트 5개

| 에이전트 | 담당 |
|---|---|
| 팀장·최종 결재 | 작업 배정, 운영 상태 관리, 검증 후 승인·보류·반려 |
| 데이터·동향 수집 | 경기 기록, 선수단·포메이션·가치, 부상·구단 소식 |
| 분석·예측 | 팀 비교, 향후 예측 모델 개발과 실행 |
| 시각화·웹 | 차트·화면·향후 서비스 연결 |
| 독립 검증·모델 평가 | 자료·계산·화면·성능을 작성자와 독립적으로 확인 |

팀장 계획 → 수집 → 분석 → 화면(선택) → 검증 → 팀장 결재. 팀장은 승인할 결과를 직접 작성하지 않습니다. 검증자와 최종 결재자도 서로 분리합니다. 최종 모델 채택·출처 변경·공개 배포 결정은 사용자에게 있습니다.

## 검사 실행

Python3.10이상에서 이 프로젝트 폴더로 이동합니다. 아래 검사는 추가 패키지 없이 실행합니다.

```sh
python -m unittest discover -s agent-team-2026-10-06-v01/tests -v
python -m unittest discover -s agent-team-integrated-2026-10-06-v01/tests -v
python agent-team-integrated-2026-10-06-v01/tools/context_cli.py validate team-run-2026-10-06-v01/data/context_records.json
python agent-team-integrated-2026-10-06-v01/tools/context_cli.py validate team-run-2026-10-06-v01/trends/records.json
```

기존7개·통합6개 규칙 시험이 통과했습니다. 실제 실행의 보조49기록은 수집26·미수집22·접근차단1, 선수단117명·지난 경기 선발44명입니다. 저장 원자료에 대한 독립대조271항목에서 차이가 없었습니다. 대표2경기 설명은 내부승인, 확률·예측서비스는 모델이 없어보류입니다. 형식과 대조 검사는 모든 제공처 사실을 인증하지 않습니다. 기본 스킬 YAML검사기는 PyYAML누락으로 실행되지 않았고 더 좁은 이름/설명/참조 검사로 구분해 기록했습니다.

## 자료와 미래 경기 사용

계획 범위는 PL·라리가2023/24~2025/26과 진행된2026/27입니다. 경기 결과·날짜·기대득점(xG: 슈팅 기회의 질을 골수로 환산한 값)은 Understat, 겹치지 않는 시즌통계는 StatMuse입니다. 공식일정 보정·풋볼데이터·배당·챔스는 제외합니다.

미래 경기는 예측 대상입니다. 학습에는 과거 경기 당시 시작 전 알 수 있던 정보만 입력하고, 실제 결과는 정답으로 사용합니다. 미래 실제선발 미발표를 기본모델 예측의 필수조건으로 강제하지 않습니다.

공개 패키지에는 **종료20경기·예정2경기의 시연 부분자료**만 포함하며 전체학습자료가 아닙니다. 전체사이트 캐시·개인환경 실행 스크립트는 로컬에 보존합니다. 실행근거는 공개용으로 정리한 사본이라 최초 검증에 사용한 모든 원문이 포함되지는 않습니다. 시장가치는6월1일 추정치, 선수단은10월조회자료로 시점이 다릅니다. 기사 기준일 추정·전체부상/이적/휴식일 미확보·시각 미확인을 유지합니다.

## 버전 관리와 포트폴리오 의미

[VERSION](VERSION) · [변경 이력](CHANGELOG.md) · [버전 규칙](docs/VERSIONING.md) · [파일별 내용 해시](publication_manifest.json)를 보존합니다. 해시는 파일 내용이 바뀌었는지 대조하는 값입니다. 공통스킬과 Codex/Claude용사본을 함께 보존하며 모델을 고정하지 않습니다. 설정이 있다는 것과 양쪽에서 실제 실행한 것은 구분합니다.

다른 분야에서도 설명할 역량은 출처 연결·누락 처리·시점 오류 방지·작성자와 검증자 분리·근거에 따른 승인입니다. 향후 구현은 과거→미래 검증이 가능한 기본 예측모델, 모델평가, 자동갱신, 서비스 연결입니다.
