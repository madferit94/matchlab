# MatchDesk 5인 팀 공통 규칙

TEAM-PROTOCOL.md와 team.json을 읽고 roles/<agent>.md 및 skills/matchdesk-<agent>/SKILL.md를 따른다. 다섯 에이전트는 통합 책임 단위이며 실행 환경의 동시 작업 수에 맞춰 순차/병렬로 배정한다. 모델과 AI 제공자를 고정하지 않는다. 상위 실습 지침과 작업일지.md 하나를 유지하고 원본·기존 결과를 보존한다.

자료는 ../source-unified-2026-10-06-v01. Understat 기본 경기/날짜/xG, StatMuse 추가 통계 정책과 챔스 제외를 유지한다. Football-Data·배당은 초기 제외 대상이었으나 2026-10-08 사용자 요청으로 아래 범위에 한해 허용한다. 미래 경기는 예측 대상이다. 과거 경기 시작 후 정보를 학습 입력에 포함하지 않는다. 내부 분석 승인은 사용자 모델 채택·출처 변경·공개 배포 결재가 아니다.

## 0.24.0 배당 통합 범위
- ../modeling/odds-0.24.0/의 Football-Data 마감 배당은 경기 매칭·경기 직전 회고 학습에만 사용한다. 기본 경기 지표나 날짜를 덮어쓰지 않는다.
- 관측 timestamp 미확인으로 24시간 전 예측이라고 주장하지 않는다. 예정 배당 미확보 시 기존 모델을 유지하며 배당 결합 적용으로 표시하지 않는다.
- 초기 보류 4경기 유지. 결합 모델은 배당단독보다 낮은 결과도 함께 기록한다. 이번 통합의 자가 점검은 독립 에이전트 결재가 아니다.
