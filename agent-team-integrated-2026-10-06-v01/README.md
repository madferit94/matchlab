# MatchDesk — 통합 5인 에이전트 팀

기존 10개 역할을 5개 실행 담당으로 통합했습니다. 기능은 유지하고 담당 간 전달 횟수를 줄였습니다.

| 에이전트 | 합친 기존 역할 | 맡을 일 |
|---|---|---|
| 팀장·최종 결재 | 팀장 + 운영 + 최종 승인 | 작업 배정, 갱신 상태 관리, 검증 후 내부 결재 |
| 데이터·동향 수집 | 데이터 + 최근 동향 | 경기 기록, 선수단·포메이션·가치, 부상·소식 수집 |
| 분석·예측 | 분석 + 예측 | 팀 비교, 과거 학습, 미래 경기 확률 계산 |
| 시각화·웹 | 시각화 | 차트와 웹 화면, 예측 결과 연결 |
| 독립 검증·모델 평가 | 검증 + 모델 평가 | 자료·계산·화면·예측 성능 독립 확인 |

**팀장 → 수집 → 분석·예측 → 시각화 → 검증 → 팀장 결재**로 진행합니다. 팀장은 직접 결과를 작성하지 않아 최종 결재의 독립성을 유지합니다. 팀장과 최종 결재는 한 에이전트의 두 단계입니다. 최종 사업 결정은 사용자에게 있습니다.

공통 스킬5개, Codex용 사본5개, Claude용 사본5개와 Claude 하위에이전트 정의5개를 포함합니다. 모델을 고정하지 않습니다. 운영 상태를 포함한 기존 기능 보고서 형식과 승인 규칙은 보존하고, integrated_gate.py가 통합 담당/독립성을 추가 확인합니다.

미래 경기는 학습할 자료가 아니라 예측 대상입니다. 미래 실제 선발 미발표는 기본 모델 예측을 막는 조건이 아닙니다. 현재 실제 예측 모델은 미구현입니다. 역할 통합으로 모델이 생성되지는 않습니다.

이 버전은 새 구성과 검사 코드입니다. 대표2경기의 기존 실제 팀 실행은 이전 10역할 배정으로 수행됐으며 통합5인 실행으로 재표기하지 않습니다. Claude 실제 실행·API 자동 실행기는 미검증/미구현입니다. 기존 agent-team-2026-10-06-v01과 실제 수집 결과는 보존합니다.
