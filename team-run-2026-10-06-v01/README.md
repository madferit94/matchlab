## 실제 수집 범위

- 4팀 선수단117명, 지난 경기 실제 선발44명 및 포메이션4개.
- 4팀 추정 선수단 시장가치: 모두 **2026-06-01·유로 기준**. 10월 현재 가치나 같은 시점 선수단 가치로 주장하지 않습니다.
- 일부 구단·리그 동향: 대표팀 철수·훈련·과거 감독 기자회견 등. 다음 경기 결장과 선발 확정으로 해석하지 않습니다.
- 합계49기록: 수집26·미수집22·접근차단1. 기록 수이며 전체 지표 확보율이 아닙니다.

전체40팀·전체시즌 보조정보 수집 완료가 아닙니다. 팀별 과거 선발과 조회 시점 선수단은 선수 통합 ID 없이 출처 표기와 팀/경기 키로 연결했습니다. 최근 이적·전체 징계·부상 명단, 모든 경기 포함 실제 휴식일은 미확보입니다.

## 실행 환경과 남은 구현

현재 Codex에서 실제 하위 에이전트 실행을 확인했습니다. Claude 명령은 검색되지 않아 실제 실행을 검사하지 못했습니다. 공통 규약과 두 도구용 스킬을 구성한 것과 양쪽에서 실동작을 검증한 것은 구분합니다.

기본 Understat 자료는 기존 선택 버전이며 이번 실행에서 갱신하지 않았습니다. 자동 수집·정기 갱신·승리 확률 모델·예측 API·공개 웹서비스는 미구현입니다. 내부 분석 승인은 공개 배포나 모델 채택 결정을 대신하지 않습니다.

기존 결과와 화면 v01/v02는 보존했습니다. 최종 화면은 **index-v03.html**입니다.
