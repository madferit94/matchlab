# 후보 1 · 부드러운 분석 앱 적용 예시

v12를 보존하고 실제 기능이 연결된 미리보기를 만들었습니다. 디자인 채택 확정 전 예시입니다.

| 영역 | 적용 예시 |
|---|---|
| 전체 배경 | 따뜻한 밝은 바탕, 하얀 카드, 잔잔한 그림자 |
| 상단 메뉴 | 밝은 헤더와 둥근 탭으로 부드러운 첫인상 |
| 팀 종합 정보 | 큰 팀 이름·로고와 팀 색상의 옅은 배경 |
| 핵심 숫자 | 경기·승점·승무패·득실점을 작은 둥근 카드로 구분 |
| 상세 통계 | 얇은 테두리 대신 배경과 간격으로 구분, 이름을 눌러 풀이 |
| 검색·필터 | 둥근 입력창과 묶음 배경으로 한 영역임을 표시 |
| 모바일 | 기존 한 열/두 열 배치와 긴 이름 줄바꿈 유지 |

팀 배경과 승점 강조색은 팀 선택에 따라 바뀝니다. 기존 통계·검색·필터·지표 말풍선은 그대로 작동합니다. 출처 영역과 외부 경기 링크도 계속 숨겨져 있습니다.

검증: Node VM 동작 검사 35개 통과. 실제 브라우저에서의 모양과 사용자의 선호는 확인 전입니다.
