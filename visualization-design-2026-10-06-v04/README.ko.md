# 팀 로고와 과거 기록 v04

최종 화면은 index-v02.html입니다. v03은 보존했습니다. 초기 index.html/logo-manifest.json도 남기고, 파일명에 logo가 없었던3팀을 실제 관찰된 주소로 보완한 v02를 별도 저장했습니다.

56팀의 로고 주소를 기존 StatMuse 원본 페이지의 og:image에서 추출했습니다. 합성 공유 이미지의 인코딩된 원본 URL에서 로고 경로를 읽었으며 임의 구단 ID나 파일명을 추측하지 않았습니다. 로고 URL·팀 ID·원본 페이지·제목·원본 파일 해시는 logo-manifest-v02.json에 있습니다. 로고 이미지를 다운로드해 보관하지 않고 외부 이미지로 연결합니다. 파일명과 페이지 증거로 연결했으며56개 이미지를 눈으로 구단별 대조한 검사는 아닙니다.

카드/팀비교/리그표/기록표의 팀 로고는 과거 기록을 여는 링크입니다. 경기 카드는 로고 링크와 분석 버튼을 분리하여 클릭 충돌과 중첩 버튼을 피했습니다. 팀 링크는 해당 리그와 팀을 선택하고 #team=팀ID 주소로 연결합니다. 로고를 불러오지 못하면 같은 위치에 팀 이니셜이 표시되며 기록 링크는 유지합니다.

팀 화면: 4시즌 승점·승무패·득실점·경기당xG, 경기당승점 비교, 선택시즌 홈/원정 성적, 해당시즌 전체경기 기록. 시즌 표의 시즌명을 선택하면 상세시즌을 바꿉니다. 장소와 승/무/패 필터는 경기 목록에 적용합니다. 시즌 요약은 전체 시즌 기준으로 유지하고 목록의 표시경기/전체경기 수를 구분합니다. 시즌별 표본 수와 진행중시즌 상태를 표시합니다.

범위는 저장된PL/라리가2023/24~2026/27 자료이며 팀의 전체 창단 역사나 다른리그·컵대회 기록이 아닙니다. 최신 완료일2026-09-20, 재수집없음. 기록없는시즌은 결측으로 표시합니다. 모델과 승리확률을 수정하지 않았습니다.

실제 브라우저의 로컬주소 접근은 앞선file://보안제한 때문에 우회하지 않았습니다. Node VM과 모의DOM으로 클릭처리·시즌집계·필터논리를 검사하며 실제 이미지 렌더/모바일/키보드 화면 검증과 구분합니다. HEAD 검사는 이미지 응답상태만 확인하며 이미지 내용·화면표시 검사가 아닙니다. 참가자 확인 전, push/배포 미수행입니다.

실행 결과: Node VM 논리 검사14개 통과.56개 로고 주소의 HEAD 상태는 모두200이며, MIME은55개 application/octet-stream·1개 image/png였습니다. logo-header-check.json의 ok=1은 엄격한 image/* 헤더 조건을 만족한 개수이며 정상HTTP응답 수를 뜻하지 않습니다. 모두 브라우저에서 표시된다고 주장하지 않습니다. 최초3팀 누락은 파일명에 logo가없던실제관찰주소를허용하여보완했고, 검사정규식이서로다른버튼을걸쳐일치한문제는각버튼내부만검사하도록수정했습니다.
