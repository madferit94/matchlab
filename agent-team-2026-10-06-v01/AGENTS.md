# MatchDesk 공통 작업 규칙

TEAM-PROTOCOL.md와 team.json을 읽고 해당 역할의 skills/matchdesk-<role>/SKILL.md를 적용한다. 원본 데이터는 ../source-unified-2026-10-06-v01이다. 모델이나 AI 제공자를 역할 문서에 고정하지 않는다. 실제 사용 가능한 하위 에이전트 도구로 역할을 배정하고, 병렬 기능이 없으면 같은 입출력 계약으로 순차 실행한다. 문서만 만들었다고 팀 실행 완료로 표현하지 않는다.

기본 경기·일정·xG는 Understat, 추가47종은 StatMuse, 포메이션·선발·시장가치·동향은 별도 보조 자료다. 공식 일정 보정은 사용자의 새 결정 없이 적용하지 않는다. 미수집 항목을 값0 또는 확정 정보로 채우지 않는다. 확률은 실제 계산 코드의 검증된 결과만 사용한다. 사용자 결재는 출처 정책 변경·모델 채택·공개 배포에 적용한다.

상위 실습 폴더 작업일지.md 하나에 기록한다. 기존 파일 보존·한국어 존댓말·참가자 확인 전 상태를 유지한다.
