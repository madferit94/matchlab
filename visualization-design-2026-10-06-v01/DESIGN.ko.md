# MatchDesk 시각화 설계 v01

작성일: 2026-10-06. 상태: 화면 설계, 참가자 확인 전. 기존 화면과 모델은 변경하지 않습니다. 이번 산출물은 운영 서비스가 아닌 정적 화면 설계 미리보기입니다.

## 설계 방향

FotMob의 경기·팀 탐색 구조와 Opta Analyst의 차트+해설 구성을 참고합니다. 홈페이지는 경기 선택, 팀 화면은 최근 변화, 경기 화면은 두 팀 비교에 집중합니다. 그래프에서 근거 경기 목록으로 이동할 수 있도록 설계합니다. AI는 수치에 연결된 짧은 해설을 제공하며, 최종 판단을 대신 확정하지 않습니다.

참고: [FotMob 팀 페이지](https://www.fotmob.com/teams/9825/overview/arsenal), [Opta 예측 분석](https://theanalyst.com/articles/premier-league-predictions-2025-26-opta-supercomputer), [Understat 실제 경기 페이지](https://understat.com/match/22275), [Sofascore 경기 흐름 설명](https://www.sofascore.com/news/understanding-football-match-stats-how-attack-momentum-and-big-chances-impact-performance). 시각 배치의 제안이며 해당 사이트의 계산 모델이나 데이터 사용 권한을 가져오는 것이 아닙니다.

## 현재 좌표 자료 확인

기존 과거 3시즌 6개와 진행 시즌 2개 Understat 원본을 압축 해제하여 모든 중첩 필드를 검사했습니다. 최상위는 teams/players/dates입니다. X·Y 좌표 쌍, 슈팅 사건 목록, shotsData/shotData 필드는 없습니다. players[].shots는 시즌 합계이며 players[].time도 시즌 출전 시간입니다. 경기 중 슈팅 시각으로 쓰지 않습니다. HTML/JSON 보관 파일의 좌표·shotsData 검색에서도 해당 필드가 발견되지 않았습니다. 상세 근거는 coordinate-audit.json에 저장합니다.

현재 자료는 리그 응답을 수집한 것이며, 경기 상세의 슈팅 사건을 수집한 것이 아닙니다. Understat 경기 페이지에서 Field/Timing chart를 확인했지만, 현재 도구로 경기 상세 데이터 응답은 읽지 못했습니다. 따라서 실제 사건 필드, 좌표 범위·방향, 시즌 전체 수집 가능 여부는 아직 미확인입니다. 선수 시즌 합계에서 경기별 위치를 복원하지 않습니다.

## 자료별 시각화

| 시각화 | 현재 가능 여부 | 자료와 해석 |
|---|---|---|
| 최근 5경기 승·무·패 | 가능 | 완료 경기 날짜·득점으로 계산, 각 경기를 클릭해 상세로 이동 |
| 경기별 xG·xGA 추이 | 가능 | 팀 경기별 기대 득점·기대 실점. 경기 안의 분 단위 흐름과 구분 |
| 실제 득점−xG | 가능 | 결과와 기회 창출의 차이. 차이를 운이나 결정력으로 단정하지 않음 |
| 홈·원정 / 시즌 비교 | 가능 | 동일 리그·기간·경기당 평균 사용. 표본 수 항상 표시 |
| 팀 공격·수비 분포도 | 가능 | 가로축 경기당 xG, 세로축 경기당 xGA. 수비는 낮을수록 좋다는 설명 |
| 압박 관련 PPDA 비교 | 조건부 가능 | ppda_att/ppda_def 비율, 분모 0은 결측. 작을수록 강한 압박의 참고값, 리그·시즌 구분 |
| 경기장 슈팅 지도 | 추가 수집 | 슈팅별 좌표·팀·선수·xG·결과 필요 |
| 슈팅 구역 분포 | 추가 수집 | 좌표 방향 검증 후 구역별 슈팅 수·xG 합계, 슈팅 위치 분포로 명명 |
| 경기 중 누적 xG | 추가 수집 | 슈팅별 발생 시각과 xG, 추가시간 표기 규칙 검증 필요 |
| 선수 이동 / 패스 연결망 | 현재 범위 불가 | 슈팅 위치로 선수 이동이나 패스 연결을 만들어내지 않음 |
| Sofascore식 공격 흐름 | 현재 범위 불가 | 슈팅만으로 동일한 지표를 재현할 수 없음 |

## 화면 1 — 경기 탐색

상단: MatchDesk / 경기 / 팀 / 리그. 리그(PL·라리가), 시즌, 기간 필터를 제공합니다. 기본은 진행 시즌입니다. 수집 기준일과 원본 시간대 미확인 상태를 작게 표시합니다.

본문: 예정 경기와 종료 경기를 별도 구획에 둡니다. 예정 카드는 팀명·자료상 날짜·최근 5경기 요약을 보여줍니다. 종료 카드는 스코어와 양 팀 xG를 보여줍니다. 날짜만 확인된 경우 임의의 한국 시간 킥오프를 쓰지 않습니다. 경기 카드 선택은 경기 분석으로 연결합니다.

## 화면 2 — 경기 분석

상단: 홈팀 대 원정팀 / 리그 / 날짜 / 예정 또는 종료 상태. 예정 경기에는 실험 승·무·패 확률을 가로 100% 막대로 배치하고 '실험 모델'을 표시합니다. 종료 경기에는 실제 결과와 xG를 표시합니다. 사전 예측 기록을 저장하지 않은 과거 경기에는 사전 예측처럼 확률을 표시하지 않습니다.

1. 요약: 최근 5경기 승점·득점·실점·xG·xGA를 나란히 보여줍니다.
2. 팀 비교: 같은 축의 가로 막대로 비교하며 최근 5경기/시즌, 전체/홈·원정 필터를 둡니다. 기본 비교는 양 팀 최근 5경기 전체입니다. 홈팀 홈경기와 원정팀 원정경기는 별도 선택으로 분리합니다.
3. 최근 흐름: 양 팀의 경기별 xG·xGA 추이와 승·무·패를 표시합니다. 각 점에는 날짜·상대·득점·원본 링크를 제공합니다.
4. 경기 상세: 종료 경기에서만 슈팅 지도·누적 xG를 제공합니다. 자료 미수집이면 빈 상태 안내를 보여주고 임의의 점을 그리지 않습니다. 예정 경기에서는 해당 경기 슈팅 지도를 숨기며 과거 비교 경기로 이동하는 링크만 제공합니다.
5. 분석 설명: 핵심 변화 3개와 근거 경기 목록. 수치 설명은 작성 가능하나 이번 정적 미리보기에는 AI 분석이 실제 실행됐다고 표시하지 않습니다.

## 화면 3 — 팀 분석

팀 이름과 시즌을 고르고 최근 5/10경기·전체 시즌을 전환합니다. 경기당 xG/xGA와 실제 득실점, 최근 승점, 홈·원정 차이를 보여줍니다. 하단에는 경기 결과 목록과 추가 수집 후 가능한 슈팅 구역 분포를 배치합니다. 최근 5경기와 시즌 평균의 변화를 비교하되 표본 수와 포함 날짜를 밝힙니다.

## 화면 4 — 리그 분석

순위표와 공격·수비 분포도를 같은 페이지에 배치합니다. 순위표는 승점 기준이며 동률 순위 규칙이 검증되지 않았다면 '승점순 통계표'로 표시합니다. 완료 경기만 집계하고 날짜·출처를 기록합니다. 서로 다른 리그의 원시 수치를 같은 표에서 단순 서열화하지 않습니다. 팀 선택 시 팀 분석으로 연결합니다.

## 슈팅 자료 추가 시 계약

목표 필드: match_key, shot_id, team_key, player_id, player_name, minute_raw, X_raw, Y_raw, xG, result, situation, shot_type, source_url, fetched_at_utc. 이 목록은 요구 필드이며 실제 응답 확인 완료 목록이 아닙니다. 제공되지 않는 필드는 결측으로 둡니다.

- 기존 Understat 경기 ID로 연결합니다. 팀명 문자열이나 날짜만으로 합치지 않습니다.
- 샘플 PL·라리가 종료 경기에서 필드, 좌표 범위와 공격 방향, 득점 위치를 원본 화면과 대조한 뒤 변환 규칙을 확정합니다. 좌표가 0~1인지 먼저 확인하며, 105×68m 환산을 실제 경기장 측량값처럼 표현하지 않습니다.
- 지도에서 점 면적은 xG에 비례하도록 설정합니다. 팀은 색+범례, 득점 여부는 테두리/기호로 구분합니다. 클릭·키보드 선택으로 선수·시간·결과·xG를 확인합니다.
- 팀별 슈팅 수와 xG 합계를 경기 집계에 대조합니다. 자책골·반올림·제공자 집계 차이가 있을 수 있으므로 불일치를 삭제·보정하지 않고 기록합니다. 무조건 득점 수와 Goal 사건 수가 같다고 가정하지 않습니다.
- 시즌 지도는 수집 경기 수/대상 경기 수와 필터를 표시합니다. 누락이 있으면 전체 시즌 분포로 표현하지 않습니다.
- 좌표 자료는 과거 경기 설명에 사용합니다. 미래 경기 지도는 생성하지 않습니다. 예측 입력에 포함하려면 각 경기 전에 확보된 자료만 사용해야 하며 이번 작업은 모델을 수정하지 않습니다.

## 시각 규칙과 접근성

밝은 회색 바탕·흰 패널·짙은 남색 글자, 홈팀 파랑·원정팀 주황을 기본으로 합니다. 색만으로 팀·결과를 구분하지 않습니다. 숫자는 자릿수를 정렬하고 본문은 16px 이상을 사용합니다. 팀명·한국어 설명은 운영체제 기본 한글 글꼴을 사용합니다.

데스크톱은 2열, 휴대전화는 1열입니다. 필터는 최소 44px 높이, 키보드 포커스 표시, 차트의 표 대체 보기, 마우스를 올리지 않아도 읽을 수 있는 상세 영역을 제공합니다. 차트 색·배경 대비와 좁은 화면의 축 레이블은 구현 후 검사합니다.

스킬 검색은 Data-Dense Dashboard 스타일을 제시했습니다. 함께 제시된 Enterprise Gateway/Contact Sales 패턴은 제품에 맞지 않아 채택하지 않았습니다. 좁힌 재검색도 같은 부적합 패턴을 제시하여 탐색 구조는 위 참고 사이트와 자체 설계 판단을 사용합니다.

## 구현 순서와 완료 조건

먼저 경기 탐색·팀 비교·최근 흐름·리그 분포도를 현재 자료로 구현합니다. 다음으로 검증된 슈팅 샘플을 수집하여 지도와 누적 xG를 구현하고, 범위를 넓힙니다. 모델 성능 개선은 뒤로 미룹니다.

완료 조건: 필터 변경 시 차트·표·설명·표본 수가 함께 바뀜, 차트 선택에서 근거 경기로 이동, 자료 누락과 0값 구분, 예정/종료 표시 구분, 기존 자료 미변경, 모바일·키보드 확인. 이번 산출물의 정적 미리보기는 정보 배치만 확인하며 이 동작을 완료했다고 주장하지 않습니다.
