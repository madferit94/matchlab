현재 실행기는 analysis/record-engine.cjs의 브라우저 JavaScript이며 LLM은 연결되어 있지 않다. 스킬 문서는 실행 도구가 아니다.

- 경기 식별자·팀·시즌·범위·장소·지표를 명시한다. 생략 조건은 화면 선택 팀/리그/시즌과 전체 장소·시즌 전체로 정하고 결과에 표시한다.
- 득점/실점/xG/xGA/승점/과거 승률, 팀 비교·리그 순위·홈/원정·득점/xG 추세를 현재 지원한다. 최근 N은 선택 시즌 내 완료 경기이며 장소 비교는 각 장소별 N이다.
- 모르는 지표·리그·시즌·복잡한 조건은 지원하지 않는다고 말한다. 자료 없음은 누락값이며 0으로 채우지 않는다. 미래 경기는 과거 집계에 포함하지 않는다.
- 승률은 과거 승리/경기 수이다. 승리 확률 도구는 모델 버전·시점 이전 자료·성능 검증이 연결되기 전에는 실행 불가이다.
- 계산 결과에는 조건, 자료 기준일, 실제 실행 언어, 계산식, 행별 값과 검증 상태를 보인다. 문서의 SQL/Python 계획을 실제 실행으로 기록하지 않는다.
- 도구 확장은 [도구 규격](../../docs/ANALYSIS-TOOLS.md)을 따른다. 실제 구현 담당과 검증 담당을 구분하며 이번 작업은 단일 Codex가 구현·자동 검사했다.
