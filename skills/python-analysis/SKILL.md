---

Python 실행 도구가 실제 제공될 때 사용한다. 사용자가 입력한 임의 코드를 브라우저나 서버에서 그대로 실행하지 않는다.

- SQL 결과 또는 저장된 검증 자료의 schema·단위·누락값을 확인한다. 데이터 원본을 수정하지 않고 출력만 생성한다.
- 도구가 허용한 계산 작업을 함수로 실행하고 차트와 동일한 수치 표를 반환한다. 라이브러리·코드 버전과 실행 성공/실패를 기록한다.
- 샘플 경기의 원본 값, 행 수, 합계와 평균의 분모를 독립 계산으로 대조한다. 모델 출력과 집계값을 구분한다.
- 예측은 별도 도구이다. 시간 순서에 따른 학습/검증 분리, 기준일 이후 자료 누출 방지, 비교 기준 성능·모델 버전이 없으면 채택 결과로 표시하지 않는다.
- 차트에는 제목·축/범례·단위·조건을 포함하고 결과 표를 함께 반환한다. 근거가 없는 자연어 수치 설명을 만들지 않는다.
- 실제 실행 코드와 검증 결과를 SPEC에 남긴다. 연결 전에는 실행했다고 표현하지 않는다.
