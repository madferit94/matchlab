---
name: sql-analysis
description: MatchDesk에 SQL 실행기를 연결할 때 완료 경기 조회·집계의 범위와 실행 근거를 지킨다. 현재 HTML 실행기가 SQL을 실행한다는 뜻은 아니다.
---

연결 전 상태: HTML은 JavaScript로 JSON을 조회한다. SQL 엔진·DB 연결이 제공된 작업에서만 이 스킬의 SQL 실행 절차를 적용한다.

- 요청을 팀/리그/시즌/날짜/장소 조건으로 바꾼다. completed 경기와 scheduled 경기를 분리한다.
- actual schema를 먼저 읽고 경기/팀 식별자로 결합한다. 팀 이름의 문자열 일치만으로 자료를 합치지 않는다. 한 경기의 팀별 두 행 중복을 주의한다.
- 조회용 SELECT와 바인딩된 매개변수를 사용한다. 사용자 문장을 SQL 코드로 직접 이어 붙이지 않는다. 실행 시간·행 수 제한을 설정한다.
- 분모 0·자료 없음은 NULL. 경기당 평균은 해당 팀의 실제 경기 수로 나눈다. PPDA는 분자 합/분모 합이며 경기별 비율의 단순 평균이 아니다.
- 사용한 SQL 전문·매개변수·반환 행 수·기준일을 남긴다. 이 워크샵의 SQL 실행 결과를 보고할 때 최종 답변에도 실행 SQL 전문을 포함한다.
- 다른 서비스 테이블은 현재 자료와 별도 범위로 등록한다. 신규 데이터 접근 권한과 실제 연결 여부를 먼저 확인한다.
