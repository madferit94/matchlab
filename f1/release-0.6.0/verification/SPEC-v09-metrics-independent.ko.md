# F1 0.6.0 지표 독립 검증 계획

검사 주체: `/root/f1_verifier`. 제품 작성자의 자체 검사와 분리합니다. 실행 전 작성한 기대값이며 이전 v08 자료를 보존합니다.

1. 자료 보존: 시즌 경기, 지도, 과거 예측, 미래 예측 네 JSON의 SHA-256이 v08과 같아야 합니다. UI 추가로 원본이나 모델을 재학습하지 않습니다.
2. 경기 전체 지표: 선택 선수의 유효한 양수 랩시간만 집계합니다. 평균은 합/건수, 가장 빠른 랩은 최솟값, 표준편차의 분모와 제외 조건은 도움말과 일치해야 합니다. 피트 레인 통과와 정차 시간은 다른 지표입니다. 누락은 미확보이며 임의의 0이 아닙니다.
3. 진행 시점 지표: 완료 랩은 시작+소요시간이 커서 이하, 순위·피트 진입은 해당 시각이 커서 이하입니다. 피트 총시간은 종료 시각 전까지 숨겨야 합니다. 예정 GP에 실제 결과를 생성하지 않습니다.
4. 모델 입력 도움말: 10개 변수의 최근 5회/현재 시즌/팀 5회/동일 서킷 범위와 2회 사전값 보정 공식을 원래 학습 코드 및 출력과 대조합니다. 현재 경기 결과는 모델 입력에 포함하지 않습니다.
5. UI: 한·영 도움말 버튼, 카테고리/선수 변경, 취소 GP 처리 및 최종 HTML에 최신 모듈·자료가 들어갔는지 자동 검사합니다. 정적 CSS와 가짜 DOM 검사는 실제 화면 폭/넘침 확인으로 주장하지 않습니다.

실제 화면 320·375·768·1280 폭 확인은 부모 작업자의 브라우저 근거를 별도 표시합니다. 참가자 확인 전입니다. 모델 전체 성능 인증 또는 원본 사이트 전체 사실 검증은 범위 밖입니다.
