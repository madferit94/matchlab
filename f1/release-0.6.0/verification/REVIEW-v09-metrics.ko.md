# F1 0.6.0 지표 검증

독립 검사자는 `/root/f1_verifier`입니다. 지표 산술·자료 누락 처리·한영 설명·화면 연결은 내부 확인을 마쳤습니다. 참가자 확인 전이며, 모델 정확도 전체를 인증한 결과는 아닙니다.

## 완료 범위 / 실제 대조값

- v08의 경기·지도·과거 예측·미래 예측 네 JSON은 SHA-256이 모두 같습니다.
- 종료 16GP에서 각 1선수의 유효 랩 수·평균·최고·모집단 표준편차·구간 시간·피트 횟수·레인 시간·정차 시간을 독립 재계산했습니다. 합성 60/80초의 평균 70초·표준편차 10초, 피트레인 28/32초 평균 30초와 실제 정차 2초를 구분했습니다. null·0·음수 제외, 부분 구간 포함, 미확보·실패 수집은 임의의 0으로 표시하지 않습니다. 지표/설명 산술 검사 241건 통과.
- 모델 입력 10개의 2회 사전값 보정 `(합+2×사전값)/(수+2)`, 팀 출전자별 비율과 동일 서킷 키 설명을 원래 학습 정의와 대조했습니다. 예정 7GP에는 실제 경기 지표가 없습니다.
- 가짜 DOM에서 한영 선수·항목 변경, 설명 열기·닫기·Escape·초점 복구·패널 정리 32건 통과. 최종 HTML의 25GP 한영 경로·지표 탭·5개 자료·최신 모듈 연결 160건 통과.
- 커서 이전 기록 제한 함수와 실제 기록 시간 배속 함수는 v08과 같습니다. 이전 버전의 시점 경계 시험을 새로 실행한 것으로 주장하지 않습니다.

## 발견과 조치

설명 말풍선은 예정/지도 패널에서 다른 탭으로 이동할 때 닫는 통합 호출이 없었습니다. 작성자가 `stopReplay`에서 설명을 닫도록 보강했고 최종 연결 검사로 확인했습니다. 실패 수집인데 배열이 남아 있는 경우에도 값 집계를 차단하도록 작성자가 보강했고 합성 사례를 대조했습니다.

시점 함수 SHA 검사의 첫 실행은 함수 밖에 새로 삽입한 도움말 상수까지 비교하여 실패했습니다. 제품 계산 변경이 아니었습니다. 검사 범위를 함수로 좁힌 v02에서 일치했고 v01 실패 기록을 보존했습니다. UI 검사 준비 중 UTF-8 지정/합성 예정 경기의 필수 세션 시각 누락도 검사기에서 보완했습니다.

## 미확인과 필요한 사용자 판단

가짜 DOM과 말풍선 위치 계산은 실제 화면 검사와 다릅니다. 부모 `/root`가 별도 headless Edge에서 실제 HTML을 렌더링한 `render-proof-v01.json`은 245검사·16개 화면 관측이며 오류 0, 320·375·768·1280 폭의 한영 지표/타이어 화면에서 넘침 0을 기록했습니다. 설명 열기·키보드·닫기와 미래 실제 지표 없음도 부모 실행 근거입니다. 해당 결과와 PNG를 summary에 별도 연결합니다. 사용자 브라우저를 직접 조작한 확인이나 참가자의 실제 화면 확인은 아직 없습니다. 전체 원본 통계/공식 출전 명단 검증, 모델 재학습·확률 보정, 모든 접근성 보조 도구의 확인은 이번 범위 밖입니다.
