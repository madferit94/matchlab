# MatchLab F1 과거 경기 기록 예측 모델 · 0.2.0

2025년 OpenF1 24개 GP와 2026년 종료된 16개 GP를 사용했습니다. 첫 5개 GP는 과거 기록을 쌓는 준비 기간입니다. 결과가 누락된 GP는 학습 전체에서 제외합니다. 실제 학습 29개 GP, 이후 시간순 검증 6개 GP입니다. 검증 대상: [11342, 11353, 11361, 11369, 11377, 11731]. 결과 누락 제외: [].

## 사용 지표
- 최근 5경기 완주 순위 점수
- 최근 5경기 평균 포인트
- 최근 5경기 우승 비율
- 최근 5경기 포디움 비율
- 최근 5경기 미완주·미출발·실격 비율
- 해당 시즌 이전 경기 순위 점수
- 팀 최근 5개 GP 순위 점수
- 팀 최근 5개 GP 우승 비율
- 같은 서킷 이전 경기 순위 점수
- 같은 서킷 이전 우승 비율

순위 점수는 (참가 인원−완주 순위)/(참가 인원−1)로 계산하며 높을수록 좋은 과거 순위입니다. 기록이 적을 때 2경기 분량의 고정 중립값을 섞습니다. 신인이나 첫 서킷은 중립값부터 시작합니다. 팀은 원문 팀명, 드라이버는 정규화한 전체 이름으로 연결합니다. 시즌마다 바뀌는 차량 번호로 과거 선수를 동일시하지 않습니다. 서킷은 GP 명칭이 아닌 실제 circuit_key로 구분합니다. 대상 경기 시작 전에 끝난 경기만 입력하고, 자료 경기수는 표시용이며 학습 변수에 넣지 않습니다.

## 학습과 검증
로지스틱 회귀는 과거 지표로 선수별 우승 점수를 학습합니다. 각 GP 안에서 점수를 확률로 정규화해 합계 100%로 만듭니다. 별도의 회귀 모델은 평균적인 완주 순위를 추정합니다. 설정은 검증 전에 고정했고 검증 성능을 보고 바꾸지 않았습니다. 검증 6경기 동안 모델 자체는 고정하되 이미 끝난 검증 경기는 다음 경기의 과거 기록에 반영합니다. 현재 경기 랩·결과·시즌 최종 순위·미래 날씨·출발 그리드는 입력하지 않았습니다. 순위 정답 누락은 순위 학습에서 제외합니다. 당시 참가자는 과거 drivers 원문으로 구분하지만 그 명단의 경기 전 공개시점은 별도로 확인하지 못했습니다.

| Model | Log loss ↓ | Brier ↓ | Top-1 |
|---|---:|---:|---:|
| model | 3.1195 | 0.8646 | 33.3% |
| recent_win_baseline | 2.9699 | 0.9713 | 11.7% |
| uniform | 3.0910 | 0.9545 | 4.5% |


예상 순위 평균 오차: 2.530계단. Top-1은 우승자를 맞힌 비율이며 동률이면 해당 선수들에 적중 점수를 균등 배분합니다. 우승하지 않은 대부분의 선수를 맞혔다는 방식으로 정확도를 부풀리지 않습니다. Log loss/Brier는 확률 오차이며 낮을수록 좋습니다. Brier는 참가자 전체 오차 합계입니다. 모델은 Brier·우승 적중률에서는 낫지만 Log loss에서는 두 기준선보다 나빴습니다. 따라서 확률 예측이 더 우수하다고 주장할 수 없는 실험 버전입니다. 검증이 6경기뿐이므로 높은 성능을 보장하지 않습니다.

## 예정 경기
평가를 먼저 저장한 다음 종료 경기로 다시 학습해 예정 7개 GP를 예측했습니다. 아직 열리지 않은 앞선 GP 결과를 뒤 GP 입력으로 만들어 넣지 않습니다. 최신 종료 GP의 22명은 예상 명단이며 미래 공식 참가명단이 아닙니다. 예상 순위는 소수점 평균값이므로 1~22위가 하나씩 배정되는 확정 순위표가 아닙니다. 확률 합계 100%가 실제 확률 정확성 검증을 의미하지 않습니다. 2026년 규정 변화, 작은 표본, 그리드·날씨 미반영을 고려해야 합니다. 취소 GP는 예측하지 않습니다.
