# 경기 전 모델 예측과 실제 결과 비교 · 0.3.0

종료된 2026년 16개 GP를 각각 그 경기 시작 전으로 되돌려 예측했습니다. 각 GP마다 시작 전에 끝난 경기만으로 모델을 다시 학습합니다. 첫 2026년 GP는 2025년 19경기, 16번째 GP는 이전 34경기를 학습합니다. 첫 5개 2025년 GP는 과거 기록을 쌓는 준비 기간입니다. 현재 대상 경기의 정답은 자기 예측 학습에 들어가지 않습니다. 학습 경기 번호·최신 자료 종료 시각은 `historical-feature-audit.json`에 남겼습니다.

사용 지표는 최근 5경기 순위 점수·포인트·우승 비율·포디움 비율·미완주 비율, 해당 시즌 이전 경기 순위 점수, 팀 최근 순위 점수·우승 비율, 실제 같은 서킷의 이전 순위 점수·우승 비율입니다. GP 이름 대신 실제 서킷 번호로 연결하며 시즌마다 달라질 수 있는 차량 번호를 선수 식별자로 사용하지 않습니다. 기록이 없는 선수·서킷은 중립값부터 시작합니다.

`historical-predictions.json`의 `drivers`는 예측 자료입니다. `predicted_order`는 소수점 예상 순위를 정렬해 만든 고유 1~22위의 시각화용 순서입니다. 평균 예상 순위와 실제로 하나씩 배정하는 순위는 구별합니다. `actual.drivers`의 실제 결과·미완주·미출발·실격은 별도 비교 자료이며 이 GP의 예측 입력으로 사용하지 않습니다.

예측 레이스의 움직임은 **예상 최종 순위를 보여주는 연출**입니다. 랩별 속도·추월·피트스톱·리타이어를 예측한 시뮬레이션이 아닙니다. 실제 대상 경기의 랩·시간을 예측 레이스 움직임에 섞으면 안 됩니다.

| 16개 GP의 과거 재현 평가 | 모델 | 최근 우승 비율 기준 | 균등 확률 |
|---|---:|---:|---:|
| 우승 적중률, 동률은 균등 배분 | 25.0% (4/16) | 26.25% | 4.55% |
| 확률 오차 Log loss, 낮을수록 좋음 | 2.7249 | 2.8225 | 3.0910 |
| 참가자 확률 오차 합 Brier, 낮을수록 좋음 | 0.9483 | 0.9337 | 0.9545 |

소수점 평균 예상 순위 오차는 2.950계단, 고유 1~22위로 배정한 순서의 오차는 3.713계단입니다. 모델은 Log loss가 개선됐지만 우승 적중률과 Brier는 최근 우승 비율 기준보다 나빴습니다. 더 우수한 예측이라고 단정하지 않습니다.

이는 지금 과거를 재현한 분석이며 경기 전에 실제 공개했던 예측이 아닙니다. 참가 명단도 해당 경기가 끝난 후 수집한 자료이므로 당시 명단의 경기 전 공개시점은 확인하지 못했습니다. 출발 그리드·미래 날씨·시즌 최종 순위를 입력하지 않았습니다. 16경기 재현 평가는 새로운 미래 검증이 아니며 이전의 마지막 6경기 고정 모델 검증을 대체하지 않습니다. 확률 보정 미검증·작은 표본·2026년 규정 변화의 한계가 있습니다. 기존 예정 7개 GP 예측은 별도로 유지했습니다.

`train-historical.py` → `check-historical.py`로 재현합니다. 기존 `train.py`의 선언만 구문 분석으로 꺼내 사용하므로 전역 학습·출력 코드를 실행하거나 기존 예측 파일을 덮어쓰지 않습니다. v03 원본은 보존했습니다. 자체 검사 834개 통과이며 독립 검증과 최종 결재는 별도입니다.
