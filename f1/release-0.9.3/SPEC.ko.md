# MatchLab 0.22.3 / F1 0.9.3

요청: 타이어 종류를 누르면 특성과 쓰임새를 간략한 말풍선으로 설명.
적용: 타이어·피트 탭의 구간 기록, 지도 재생 선택 선수의 현재 타이어, 기록 재생 목록. 소프트·미디엄·하드·인터미디어트·웨트 5종, 한영 지원. 기록의 컴파운드 원본 유지; 미확보는 설명 버튼 없이 — 표시.
상호작용: 버튼 클릭·Enter로 열기, 같은 버튼/닫기/Escape/바깥 클릭으로 닫기. Escape/닫기는 버튼으로 초점 복귀. 44px 클릭 영역, 16px 설명 글자, 화면 내부 배치. 재생 갱신 시 같은 타이어·선수의 말풍선 유지; 타이어 변경/탭 이동 시 닫기.
근거: 공식 F1·피렐리 설명을 요약. 소프트/미디엄/하드는 GP에 선택된 3종의 상대 분류이며 고정 C번호로 매칭하지 않음. 수명·속도·교환 횟수는 조건에 따라 달라져 보장하지 않음.
