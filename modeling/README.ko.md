# 첫 경기 전 예측 모델 — 로컬 개발

[English](README.md) | [한국어](README.ko.md)

GitHub0.2.1을받은뒤시작한 **미공개 실험**입니다. 이전 실행을바꾸어기록하거나5인전체실행을완료했다고표현하지않습니다. 코드와검사는현재로컬변경, 생성결과는Git추적에서제외합니다. 예측웹서비스는배포하지않았습니다.

## 무엇을 학습하나요

홈승·무승부·원정승 세경우의확률을학습하는 로지스틱모델입니다. 팀별직전리그5경기의승점·득실점·기대득점과자료건수, 리그경기간날짜간격을사용합니다. 날짜간격은컵/대표팀을포함한실제휴식일이아닙니다. 이전기록이없는팀은정해둔중립값과기록0건표시를사용하며, 실제자료를확인했다고표현하지않습니다.

같은날경기들의입력값을먼저모두계산한뒤당일결과를추가기록합니다. 시간대가불확실하기때문에같은날결과도미리사용하지않습니다. 과거경기입력에는더이른날자료만사용하고, 실제결과는정답입니다. 미래경기의결과는읽어학습하지않습니다.

2023/24학습→2024/25설정조정→첫두시즌으로다시학습해2025/26평가→2026/27추가점검입니다. 평가시즌의정답으로모델설정을고르지않습니다. 미래2경기는완료2399경기를모두다시학습한실험모델로계산합니다. 숫자의평균/표준편차도해당학습구간에서만계산합니다.

**진행 중인 2026/27 시즌 119경기에서는 모델이 뒤졌습니다.** 적중률은 모델 39.50%·기준 41.18%, 높은 확률로 고른 결과의 확신과 실제 적중률 차이(ECE)는 모델 15.16%·기준 3.48%였습니다. 이 지표는 작을수록 좋습니다. 현재 모델은 새 시즌의 성능과 확률 신뢰성을 확보하지 못했으므로 서비스용으로 채택하지 않습니다.

시간누출·목표결과미사용·확률안정성·재불러오기·득점입력에대한5검사통과. 첫실행은득점문자열`0.0`을정수로읽지못해중단됐고, 정수인소수표기는받되소수득점/음수/비정상값은거부하도록수정했습니다. 원본자료변경없음. 독립검토는별도`review-2026-10-06-v01`에기록합니다.

## 재실행 방법

Python 3.11 이상과 NumPy 2.3.5가 있는 환경에서 MatchDesk 프로젝트 폴더로 이동합니다. 실제 실행 환경은 Python 3.12.14였습니다. 아래 자료 경로는 전체 로컬 자료 경로로 지정합니다.

```sh
python -m unittest discover -s modeling/tests -v
python modeling/train_baseline.py --dataset /전체자료경로/source-unified-2026-10-06-v01 --cutoff-date 2026-10-06 --out modeling/runs/새로운실행명
```

GitHub의20경기시연자료로는3시즌학습을할수없습니다. 출력폴더는매번새이름을사용하며이미있는결과를덮어쓰지않습니다. 이번에패키지를설치하지않았습니다.

## 아직 확인되지 않은 부분

기본자료재수집없음, 마지막완료일9월20일입니다. 따라서 **저장자료기반임시확률**이며현재최신전력예측이나사용자채택모델이아닙니다. 부상·포메이션·현재시장가치·StatMuse시즌누적·배당은입력에서제외했습니다. 신규/승격팀의부족한과거자료, 상대전력보정, 확률보정, 사용자모델채택은다음검토대상입니다.

로컬`runs/2026-10-06-v01`에서`metrics.json`은평가결과, `predictions.csv`는미래2경기확률, `model.json`은학습값, `input_manifest.json`은자료해시와시점근거입니다. 참가자확인전입니다.
