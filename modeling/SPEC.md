# 실행 전 검증 계획 — 첫 경기 전 예측 모델

## 요청과 범위

GitHub 최신0.2.1을 pull하여 개발을 이어갑니다. 보존된 전체 Understat 자료로 학습 가능한 첫 기준 모델과 미래2경기 예측을 구현합니다. 기존 공개20경기 시연자료와 구분하며 원본은 변경하지 않습니다. 이 실험으로 모델 채택·공개 서비스 승인을 대신하지 않습니다.

## 기대값과 근거

- 과거 경기의 특성(모델에 넣을 숫자)은 날짜가 엄격히 더 이른 경기에서만 계산합니다. Understat 시간대가 미확인이므로 같은날 결과는 모두 제외합니다.
- 과거 정답은 홈승/무승부/원정승. 미래 예측에 정답은 입력하지 않습니다.
- 2023/24학습→2024/25조정→2025/26최종평가. 2026/27종료자료는 후속점검으로 별도 표시. 성능 평가 정답으로 모델 설정을 고르지 않습니다.
- 전처리 평균/표준편차는 해당 학습기간에서만 계산합니다.
- 학습기간 리그별 홈승/무/원정승 빈도를 기준선으로 비교합니다.
- 미래 실제선발·현재 누적StatMuse값·6월시장가치·10월선수단·부상 기사·배당은 학습 입력에 넣지 않습니다.
- 목표경기 결과나 같은날 다른 경기 결과를 바꿔도 목표경기 입력값은 같아야 합니다. 다른날 이전결과를 바꾸면 영향이 나타날 수 있습니다.
- 예측3확률은 유한한0~1이며 합계1입니다. 모델 파일에서 다시 계산한 값이 저장 결과와 일치해야 합니다.
- 신규 실행 폴더만 생성하고 재사용 시 덮어쓰지 않고 실패합니다.

## 상태

실행 전 작성. 실제 결과는 runs/고유실행명/metrics.json·input_manifest.json·model.json·predictions.csv에 남깁니다. 기본자료 갱신/최신성·독립 검토·확률 보정·사람 모델채택은 아직 확인하지 않았습니다.
