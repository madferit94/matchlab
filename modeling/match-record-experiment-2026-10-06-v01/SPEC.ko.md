# 경기 기록 분리 입력 실험 v01

실행 전 계획: 기존33개 입력 모델과, 경기 기록의 시즌 평균·최근5경기 평균을 분리하고 최근 승무패 비율을 추가한61개 입력 모델을 비교한다. 확보되지 않은 경기별 슈팅·클리어링·경합은 제외한다. 확정 지표 전체 모델이라고 표시하지 않는다.

- 자료: 기존 Understat 경기/팀 경기 CSV. 신규 수집 없음. 날짜는 출처 표기이며 실제 킥오프 시간대·연기 재개 시점 검증과 구분.
- 2023/24 학습 → 2024/25 정규화 선택 → 두 시즌 재학습 → 2025/26·2026/27 평가. 이미 본 평가기간이므로 회고 탐색이며 미사용 시험 자료가 아니다.
- 현재 경기 결과·같은 날짜 결과는 입력하지 않는다. 리그 평균과 결측 보정도 과거 경기만 사용한다. 표준화는 학습행만 사용한다.
- 기대 성능: 향상을 가정하지 않는다. 정답률, log loss, Brier, 확률 보정 오차, 리그별 결과를 함께 비교한다. 웹 모델 자동 교체 없음.

|검사|기대값|근거|
|---|---|---|
|당일 이후 결과 변조|해당 날짜까지 입력 동일|현재/미래 결과 누수 차단|
|미래 종료 기록 추가|앞선 입력 동일|미래 리그 평균 사용 차단|
|최근 기록 근거|모두 예측 날짜 미만|같은 날 경기 결과 차단|
|학습 표준화|학습 행에서 직접 재계산과 일치|평가자료 통계 혼입 차단|
|확률|유한수, 각0~1, 합1|승무패 확률 유효성|
|비교군|기존 저장 평가확률 재현|동일 경기/동일 기준 비교|
|원본 보존|실행 전후 파일 해시 동일|원본 및 기존 모델 보존|

실제 결과는 metrics.json·checks.json·RESULTS.ko.md에 별도 기록한다. 모델 입력은 출처의 날짜 순서 기준 누수 검사이며, 당시 온라인 공개 이력이나 수정 전 원문까지 입증하지 않는다.
