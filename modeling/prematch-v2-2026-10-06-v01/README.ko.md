# 경기 전 승부 예측 v2 · 실험 단계

분석·예측 담당 `/root/prediction_v2`가 프로젝트의 `matchdesk-analyst` 스킬과 역할 규칙을 적용해 작성했습니다. 이전 baseline 파일과 모델은 보존했습니다. 최종 채택은 독립 검증 및 팀장 판단 대상이며 자동 승인하지 않습니다.

PL과 LaLiga 실제 수집 완료 기록 2,399경기를 사용했고 마지막 완료 기록은 **2026-09-20**입니다. **2026-10-06** 기준으로 저장된 미래 일정 641경기에 실험 확률을 계산했습니다. 최신 데이터 갱신은 하지 않았습니다. 일정 날짜는 Understat 표기이며 공식 킥오프 확인을 뜻하지 않습니다.

## 입력 지표

|묶음|실제 사용|해석 제한|
|---|---|---|
|공격|득점, xG, 페널티 제외 xG, deep|deep은 전진 진입 대리지표|
|수비|실점, 상대 xG, 상대 페널티 제외 xG, deep 허용|앞선 경기의 수비 결과|
|압박|PPDA, 상대 PPDA|상대 패스/수비 행동 비율. 실제 패스 성공률 아님|
|최근 흐름|승점, 이번 시즌 최근 최대 5경기|5경기 미만은 시즌·이전 시즌·리그 평균으로 완화|
|관측량|현재/이전 시즌 경기 수, 최근 경기 수, 기록 간 날짜 간격|날짜 간격은 다른 대회를 포함한 실제 휴식 일수가 아님|

StatMuse 시즌 전체 패스 수·성공률은 해당 경기 이전 값이 없어 제외합니다. 패스 능력을 PPDA로 대신했다고 주장하지 않습니다. 부상·명단·팀 가치·배당·하부리그 데이터는 사용하지 않았습니다.

## 시즌 초반과 데이터 부족

경기 날짜보다 **엄격하게 이전**인 경기만 입력합니다. 같은 날짜 모든 경기의 입력을 먼저 만든 후 결과를 추가합니다. 이전 시즌 기록 평균을 리그 평균 8경기분으로 완화하고, 현재 시즌 평균을 이 이전 시즌 보정값 8경기분으로 완화합니다. 현재 시즌 최근 5경기는 보정된 시즌 평균 3경기분과 혼합합니다. 관측 경기 수가 늘면 실제 팀 기록의 영향이 커집니다.

이전 시즌 기록이 없는 팀은 리그 평균을 씁니다. 첫 수집 시즌이거나 승격 여부가 불명확할 수 있으므로 **승격팀이라고 확정하지 않습니다**. 하부리그 성적을 만들어 넣지 않습니다. 아무 리그 기록도 없는 첫 날짜의 중립값은 `input-manifest.json`에 공개한 설계 가정이며 실제 관측값이 아닙니다. 이 가정과 8·8·3 경기분 보정 강도는 이번 실험에서 고정했습니다.

PPDA 분모 0이면 비율을 결측으로 취급하고 보정 평균을 사용합니다. 0으로 바꾸지 않으며 해당 입력 근거에 결측 지표를 표시합니다.

## 학습과 평가

다중 로지스틱 모델은 홈승·무승부·원정승 세 결과에 합계 1인 확률을 계산합니다. NumPy만 사용합니다. 2023/24 학습, 2024/25 조정에서 정규화 강도 0.1을 선택했습니다. 2023/24+2024/25로 고정한 평가 모델을 2025/26 및 2026/27에 적용했습니다. 평가 시즌 결과로 모델 가중치를 재학습하거나 설정을 고르지 않았습니다. 평가 기간이 지나면서 당시 과거가 된 앞 경기 기록은 이후 경기의 입력에 들어갑니다.

|고정 평가 구간|경기 수|모델 정답률|리그 빈도 기준 정답률|모델 확률 오차(log loss)|기준 오차|
|---|---:|---:|---:|---:|---:|
|2025/26|760|50.92%|45.79%|1.0111|1.0680|
|2026/27 진행분|119|42.86%|41.18%|1.0313|1.0897|

확률 오차는 작을수록 좋습니다. 현재 LaLiga만 보면 정답률 43.48%가 기준 44.93%보다 낮습니다. 현재 전체의 확률 보정 오차도 약 0.112로, 2025/26 약 0.040보다 큽니다. 개선이 모든 구간에서 보장된다고 말할 수 없습니다. 기존 v1보다 좋다고 단정하지 않고 이번 동일 분할에서 단순 리그 결과빈도와 비교합니다.

미래 확률용 `model.json`은 저장된 전체 2,399경기로 재학습했습니다. 평가용 `evaluation-model.json`과 분리했습니다. 모든 미래 경기는 하나의 저장 시점을 공유하며 가상 미래 결과를 추가하지 않습니다. 먼 일정까지 같은 예측을 유지하면 낡은 예측이 되므로 실제 서비스에는 경기 전 갱신이 필요합니다. 표시는 **EXPERIMENTAL_NOT_ADOPTED**입니다. 영상은 이 확률로 만든 연출이며 실제 경기 영상이나 확정 결과가 아닙니다.

## 파일과 실행

- `train.py`: 시간 순 특징 생성, 모델 학습, 평가와 641개 미래 예측 내보내기.
- `model.json`, `evaluation-model.json`: 미래용/평가용 가중치와 표준화 값.
- `metrics.json`: 조정 시험, 평가, 리그별 상세 수치와 확률 보정.
- `historical-features.json`: 경기별 입력, 정답과 직전 기록 근거.
- `future-predictions.json`: 화면이 읽을 확률과 입력 근거. 세 결과 순서는 home/draw/away.
- `input-manifest.json`: 입력 파일 해시, 보정 규칙, 제외 지표, 마지막 기록.
- `check.py`, `check-result.json`: 작성자 자동 검사. 독립 검증과 구분합니다.

재학습은 복사한 새 버전 폴더에서 생성 JSON이 없을 때 수행합니다. 기존 결과를 덮어쓰지 않도록 `open('x')`를 사용합니다. 실제 원본 CSV는 GitHub 공개 예제보다 큰 로컬 `source-unified-2026-10-06-v01` 데이터이며 공개 예제 20경기로 학습했다고 주장하지 않습니다.
