# 첫 예측 모델 실행 결과

**과거 경기 학습과 미래 경기 확률 계산은 실행됐지만, 서비스용 모델 채택은 보류했습니다.** GitHub 0.2.1 이후의 로컬 실험이며 웹서비스에 배포하지 않았습니다.

## 사용 자료와 시간 구분

PL·라리가의 완료 경기 2,399건을 사용했습니다. 2023/24·2024/25·2025/26 시즌은 각각 760건, 2026/27 시즌은 119건입니다. 자료의 마지막 완료 경기 날짜는 2026-09-20입니다. 이번 작업에서 자료를 새로 수집하지 않았습니다.

각 경기의 입력에는 해당 날짜보다 앞선 팀별 최근 리그 경기만 넣었습니다. 같은 날의 결과도 사용하지 않았습니다. 미래 경기의 결과는 학습 정답으로 사용하지 않습니다. 부상·선발·시장 가치·배당은 이번 모델에 포함하지 않았습니다.

2023/24로 학습하고 2024/25로 설정을 조정했습니다. 이후 첫 두 시즌으로 다시 학습해 2025/26을 평가하고, 첫 세 시즌으로 학습해 2026/27을 따로 점검했습니다. 미래 2경기의 실험 확률은 전체 완료 경기로 다시 학습한 모델로 계산했습니다.

## 실제 성능

비교 기준은 학습 자료의 리그별 홈승·무승부·원정승 빈도입니다.

| 평가 자료 | 모델 적중률 | 비교 기준 적중률 | 모델 확률 오차* | 비교 기준 확률 오차* |
|---|---:|---:|---:|---:|
| 2025/26, 760경기 | 49.21% | 45.79% | 1.0280 | 1.0680 |
| 2026/27, 119경기 | 39.50% | 41.18% | 1.0756 | 1.0873 |

\* 로그 손실(log loss): 실제로 일어난 결과에 낮은 확률을 줄수록 커지는 오차로, 작을수록 좋습니다.

새 시즌에서는 적중률이 비교 기준보다 낮았습니다. 높은 확률로 선택한 결과의 확신과 실제 적중률 차이를 측정한 ECE도 모델 15.16%, 비교 기준 3.48%로 악화됐습니다. 확률 오차 일부는 개선됐지만, 모든 지표가 좋아진 것은 아닙니다. 119경기의 작은 표본과 자료 갱신이 없는 한계도 함께 고려해야 합니다.

## 검사 근거

- 작성자 검사: 시간 구분·미래 결과 미사용·확률 안정성·모델 재불러오기·득점 입력 검사 5개 통과.
- 독립 검토자: 86개 검사 오류 0. 과거 2,399경기와 미래 2경기의 입력값을 별도로 재계산해 일치 확인.
- 독립 전체 재실행: 모델·지표·과거 입력·미래 입력·예측 파일 5개가 원 실행과 바이트까지 동일. 자료 명세는 관찰 시각을 제외하고 동일.
- 처음 실행에서 CSV의 `0.0` 득점을 읽지 못한 문제를 수정했습니다. 정수에 해당하는 소수 표기는 허용하고, 음수·소수 득점·비정상값은 거부합니다. 원본 자료는 변경하지 않았습니다.
