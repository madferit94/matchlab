# 축구 지표 + 배당 · 0.24.0

111개 경기전 지표와 마감배당 확률 3개를 함께 학습한 로지스틱 모델입니다.

- 전체 2,399경기 중 2,397경기 연결, 기존 보류 4개 제외 후 2,395경기 사용.
- 학습: 2023/24·2024/25 1,518경기. 평가: 2025/26 758경기, 2026/27 119경기.
- 2025/26 정확도: 지표만 48.2% / 결합 50.0% / 배당만 학습 52.1%. 결합은 시장 기준을 넘지 못했습니다.
- 완료 경기 분석실에서 학습에 쓰지 않은 877경기의 과거 검증 확률을 비교합니다. 예정 경기 배당은 미확보이므로 기존 모델을 유지합니다.
- 경기별 배당 관측 시각과 원자료의 과거 공개·수정 이력은 미검증입니다. 24시간 전 예측이나 전향 검증이 아닙니다.

## 확인

저장소 루트에서 `npm run test:odds`를 실행합니다. NumPy가 있는 Python으로 `python modeling/odds-0.24.0/reproduce.py --out 새폴더`를 실행하면 공개된 입력으로 다시 학습하고 877개 평가 확률을 대조합니다. 출력 폴더가 이미 있으면 덮어쓰지 않습니다.

`predict.cjs`의 `predict(model, preMatchFeatures, decimalOddsHDA)`는 검증된 경기전 지표 111개와 홈승·무·원정승 배당 3개를 받습니다. 배당 누락·비정상 값은 오류입니다. 시간·경기 식별 검증은 호출자가 먼저 해야 하며 이 함수가 확보되지 않은 미래 배당을 생성하지 않습니다.
