# 전시즌 순위 대용값 추가 실험

**순위를 추가하면 예측이 좋아진다는 주장은 이번 자료에서 확인되지 않았습니다.** 기존 모델과 같은 학습 경기·학습 방식·규제계수로 비교했습니다. 운영 모델과 웹사이트는 바꾸지 않았습니다.

## 실제 결과

| 재사용 평가 자료 | 지표 | 기존 v2 | 순위 대용값 추가 |
|---|---|---:|---:|
| 2025/26, 760경기 | 적중률 | 50.92% | 49.87% |
| 2025/26 | 로그 손실, 낮을수록 좋음 | 1.011080 | 1.011412 |
| 2025/26 | Brier 점수, 세 결과의 제곱오차 합·낮을수록 좋음 | 0.606261 | 0.606555 |
| 2025/26 | 확신도와 적중률 차이 ECE, 낮을수록 좋음 | 0.039827 | 0.026639 |
| 2026/27 진행분, 119경기 | 적중률 | 42.86% | 43.70% |
| 2026/27 진행분 | 로그 손실 | 1.031313 | 1.030708 |
| 2026/27 진행분 | Brier 점수 | 0.617871 | 0.617131 |
| 2026/27 진행분 | ECE | 0.112095 | 0.128125 |

2025/26은 추가 모델이 8경기 더 틀렸습니다. 진행 시즌 적중률 증가는 1경기 차이이며 확신도와 실제 적중률의 차이는 커졌습니다. 어느 방향으로도 일반적인 성능 향상을 확정하지 않습니다. 리그별 수치와 확신도 구간별 표본은 `analyst-report.json`에 있습니다.

## 공식 순위가 아닙니다

새 입력은 이전 시즌의 **원시 경기 승점·득실차·득점으로 정렬한 순위 대용값**입니다. 380경기·20팀·팀당 38경기가 있는 EPL/라리가 시즌만 사용했고, 마지막 경기 날짜가 예측 대상 경기보다 앞서는지 검사했습니다. 현재 시즌 최종순위를 그 시즌 과거 경기의 입력으로 넣지 않았습니다.

징계에 따른 승점 삭감과 각 리그의 공식 동률 처리 규칙은 적용하지 않았습니다. 따라서 `derived-raw-tables.json`은 공식 리그 순위표로 표시하거나 운영 입력으로 사용하면 안 됩니다. 같은 승점·득실차·득점이면 팀 키로 안정적으로 정렬하며 동률 상태를 별도 기록합니다. 공식 순위 수집과 대조가 다음 단계입니다.

## 중요한 자료 부족

2022/23 자료가 없어서 2023/24 학습 760경기의 전시즌 순위가 모두 없습니다. 결측값은 중간값 0.5와 별도 결측 표시로 처리했습니다. 승격 여부는 자료 부족으로 추정하지 않았고 하부 리그 순위도 만들지 않았습니다.

2023/24만 학습한 최초 모델에서 추가 변수의 계수는 모두 0입니다. 2024/25 검증 확률도 기존 모델과 수치 오차 범위 내 동일했습니다. 즉 기존의 규제계수 선택 과정으로는 순위 변수를 평가하지 못합니다. 최종 재학습 2023/24+2024/25에서는 순위를 관측한 시즌이 2024/25 한 시즌뿐이며, 해당 760경기 중 양 팀 순위가 모두 있는 경기는 544경기입니다.

| 시즌 | 경기 수 | 홈팀 순위 없음 | 원정팀 순위 없음 | 양 팀 순위 있음 |
|---|---:|---:|---:|---:|
| 2023/24 | 760 | 760 | 760 | 0 |
| 2024/25 | 760 | 114 | 114 | 544 |
| 2025/26 | 760 | 114 | 114 | 544 |
| 2026/27 진행분 | 119 | 16 | 20 | 85 |

Transfermarkt 선수단 시장가치는 수집·입력하지 않았습니다. 현재 시장가치를 과거 경기로 옮겨서 평가하지 않습니다.

## 비교 조건과 해석 범위

기존 v2의 규제계수 0.1을 그대로 사용했습니다. 새 모델에 유리한 조건을 고르기 위한 추가 탐색은 하지 않았습니다. 2023/24+2024/25로 학습한 기존 모델의 확률이 저장된 `evaluation-model.json`과 최대 오차 1e-12 이내로 재현되는 것을 확인했습니다.

2025/26과 2026/27 결과는 기존에 확인한 평가 자료를 새 가설에 다시 사용한 **사후 탐색 실험**입니다. 새로 확보한 독립 시험 자료나 공식 채택 근거로 부르지 않습니다. 더 이른 공식 순위와 경기 당시의 시장가치 자료를 갖춘 뒤 시간을 분리한 비교가 필요합니다.

실행 주체: `/root/rank_ablation`, 통합팀 역할 `analyst`, 적용 스킬 `matchdesk-analyst`와 `python-analysis`. 자체 실행 검사는 독립 승인과 다릅니다. 화면 동작은 이번 실험의 범위가 아닙니다.

## 파일

- `experiment.py`: 실제 실행 코드. 새 출력은 같은 이름을 덮어쓰지 않고 exclusive 생성합니다.
- `analyst-report.json`: 실제 수치·조건·입력 해시·한계.
- `derived-raw-tables.json`: 공식 순위가 아닌 6개 시즌-리그 대용 순위표.
- `availability-audit.json`: 경기별 전시즌 표 날짜와 결측 여부.
- `augmented-evaluation-model.json`: 실험용 평가 모델, 웹사이트에 연결하지 않음.
- `check.py`, `check-result.json`: 자체 검사의 코드와 실제 실행 결과.

원본 자료를 변경하지 않습니다. 재실험 시 새 버전 폴더를 사용해야 합니다.
