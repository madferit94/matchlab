# 일반 화면의 출처 관리 정보 분리 · v11

- ‘출처·수집 시점’ 영역과 해당 출력 코드를 일반 페이지에서 제거.
- 일반 페이지 내 시즌 상세 통계 데이터에서도 source/observed 필드 제거. 지표 수치·말풍선·검색 보존.
- 제거한 160개 팀·시즌 출처 기록은 Git 저장소 밖의 별도 로컬 관리자 파일에 보존. 일반 페이지에는 관리자 파일 연결 없음.
- 로그인, 비밀번호, 서버의 권한 검사는 없는 정적 파일 단계입니다. 관리자 파일을 웹에 공개하면 누구나 볼 수 있으므로, 실제 관리자 전용 웹 기능은 추후 로그인·서버 권한 검사로 구현해야 합니다.
- 이전 버전과 원본 자료는 보존하므로 저장소 전체에서 출처 정보를 삭제한 것은 아닙니다.

검증: Node VM 33개 검사 통과. 일반 화면 출처 요소와 데이터 필드 없음, 검색·말풍선 유지 확인. 실제 브라우저 화면과 관리자 인증은 확인하지 않음.

참가자 확인 전: 새 팀 화면에서 출처·수집 시점 영역이 사라졌는지 확인.
