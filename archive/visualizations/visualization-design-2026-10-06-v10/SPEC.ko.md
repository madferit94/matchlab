# 지표별 뜻 말풍선 · v10

- 범위: 시즌 상세 통계 47개. 이전 v09, 원본 수치, 한글 검색, 출처 영역 보존.
- 지표 이름과 ⓘ를 하나의 버튼으로 제공. 클릭하면 해당 지표의 ‘뜻’과 ‘읽는 법’ 표시.
- 공 소유권 상실은 공 터치·패스 시도·경기 수와 함께 보도록 안내. 개별 숫자로 경기력을 확정하지 않음.
- 기존 전체 설명 토글은 개별 클릭 말풍선으로 대체.
- 한 번에 하나만 표시. 같은 지표 재클릭, ×, 바깥 클릭, Esc로 닫기.
- 키보드로 지표 버튼과 닫기 버튼 접근 가능. 명시적으로 닫으면 원래 지표 버튼으로 초점 복귀.
- 말풍선은 화면 안에 위치하도록 너비·위치를 제한. 작은 화면에서는 내부 스크롤 허용.
- 필터·팀·시즌 변경, 페이지 스크롤, 창 크기 변경 시 이전 설명 닫기. 말풍선 내부 스크롤은 유지.
- 정의 출처: v09에서 확인한 [StatMuse 공식 용어 사전](https://www.statmuse.com/product/data/fc). ‘읽는 법’은 비교·해석 시 주의할 점이며 팀 성적에 대한 자동 진단이 아님.

검증: Node VM의 화면 요소 대역으로 32개 검사 통과. 실제 브라우저 렌더링·키보드·터치 확인은 미실행.

참가자 확인 전: 팀 화면에서 ‘공 소유권 상실’을 검색한 뒤 지표 이름을 눌러 말풍선 확인.
