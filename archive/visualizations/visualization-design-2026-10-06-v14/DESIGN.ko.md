# 8비트 경기 분석실 미리보기 · v14

실제 경기 자료와 검색·필터·지표 말풍선을 유지한 8비트 디자인 예시입니다. 새로운 디자인 선택을 위한 미리보기이며, 데이터가 게임처럼 바뀌는 기능은 아닙니다.

- 짙은 게임 메뉴, 픽셀 프레임, 각진 버튼과 누를 때의 작은 이동.
- 직접 작성한 SVG 픽셀 경기장. 장식 그림이며 실제 선수 위치·포메이션·슈팅 좌표를 의미하지 않음.
- 제목·숫자에 한글 픽셀 글꼴 Galmuri11. 긴 설명과 표는 읽기 쉬운 기본 글꼴 유지.
- 깜빡임·자동 소리·가짜 레벨·확률·통계 없음. 작은 화면 줄바꿈과 키보드 초점 유지.
- 출처 영역과 경기 외부 링크는 계속 제거된 상태.

## 확인한 참고 사례

2026-10-06 확인:

- [NES.css 공식 데모](https://nostalgic-css.github.io/NES.css/): 8비트 버튼·프레임·말풍선의 방향 참고.
- [RPGUI 공식 데모](https://ronenness.github.io/RPGUI/): 게임 메뉴와 상태 표시 구성 참고.
- [Galmuri 공식 프로젝트](https://github.com/quiple/galmuri): 한글 픽셀 글꼴. 미리보기는 공식 안내와 같은 CDN 방식으로 2.40.3 버전을 요청함.

NES.css/RPGUI 코드를 복사하거나 설치하지 않고 자체 CSS와 SVG를 작성했습니다. 글꼴 파일은 저장소에 복사하지 않으며 CDN에 접근할 수 없으면 기본 글꼴로 표시됩니다. 기존 팀 로고도 외부 이미지 주소와 로딩 실패 대체 표시를 유지합니다.

Node VM 36개 검사 통과. 실제 브라우저에서 픽셀 글꼴·이미지·배치가 어떻게 보이는지는 참가자 확인 전입니다.
