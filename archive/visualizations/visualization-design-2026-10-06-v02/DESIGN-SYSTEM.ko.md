# MatchDesk 사이트 디자인 v02

작성일: 2026-10-06. 기존 v01의 정보 구조에 사이트의 시각 스타일을 추가한 설계입니다. 모델·데이터·실제 서비스 동작은 변경하지 않습니다. 참가자 확인 전입니다.

## 브랜드와 분위기

서비스 이름은 MatchDesk, 한국어 설명은 'AI 경기 분석실'입니다. 스포츠 전문 매체의 선명한 제목과 분석 도구의 정돈된 숫자를 결합합니다. 메인 화면에서 경기 선택과 비교가 먼저 보이고, 운영 에이전트의 내부 실행 기록은 분석 근거 안에서 펼쳐 봅니다.

FotMob은 탐색 순서, Opta Analyst는 그래프와 설명의 관계를 참고합니다. 자체 시각 방향은 '남색 헤더 + 밝은 분석 패널 + 라임색 강조'로 정합니다. 구단별 색이 바뀌어도 서비스의 메뉴와 상태 색은 일관되게 유지합니다.

## 글꼴과 숫자

한국어는 운영체제 기본 한글 글꼴을 사용합니다. 외부 글꼴 다운로드 없이도 화면을 읽을 수 있어야 합니다. 표와 확률에는 일정한 숫자 폭(tabular-nums)을 사용합니다.

- 화면 제목: 36px, 굵게. 휴대전화에서는 28px.
- 구역 제목: 26px, 굵게. 카드 제목: 18px.
- 기본 설명: 16px, 줄 간격 1.65. 날짜·출처: 14px.
- 실제 스코어: 40px. 확률: 28px. 단위와 기간은 옆에 명시.
- xG는 기본 소수 둘째 자리, 확률은 소수 첫째 자리, 경기 수와 득점은 정수. 반올림 전 값을 보존하고 확률 합계의 반올림 차이를 처리.

## 공간과 배치

데스크톱 본문 최대 너비 1180px, 바깥 여백 24px, 카드 사이 20px, 카드 내부 24px를 기준으로 합니다. 카드 모서리는 12px, 큰 구역은 16px입니다. 그림자는 작게 쓰고 모든 카드를 과도하게 떠 보이게 하지 않습니다.

상단은 남색 브랜드 헤더, 아래는 경기/팀/리그 메뉴입니다. 필터는 해당 분석 제목 바로 아래에 배치하고 선택 기간을 차트 제목에도 표시합니다. 700px 이하에서는 비교 카드와 차트를 한 열로 쌓습니다. 운영 화면에서는 경기와 팀 분석이 분리된 주소를 가지도록 구현하며, 현재 미리보기의 메뉴는 같은 문서 안의 구역으로 이동합니다.

## 구성 요소

| 요소 | 모양과 동작 설계 |
|---|---|
| 경기 카드 | 팀 이름을 좌우, 결과 또는 VS를 중앙. 날짜와 상태를 위에, xG·최근 흐름을 아래에 |
| 팀 비교 | 양 팀을 같은 크기로 표시. 지표는 같은 단위·축·기간. 숫자와 막대 함께 표시 |
| 필터 | 최소 44px 높이. 라벨을 유지하고 선택 상태는 글자+경계로 표시 |
| 확률 막대 | 홈승·무승부·원정승 3구간. 직접 숫자 표기, 실험 모델 상태와 계산 기준일 함께 표시 |
| 추이 차트 | 얇은 격자, 축 이름과 단위, 두 팀 선/기호 구분, 점 선택 상세와 표 보기 |
| 슈팅 지도 | 연한 경기장, 점 면적=xG, 득점 기호 강조. 좌표 검증 전에는 빈 상태 |
| 분석 설명 | 한 문장 핵심 판단 + 근거 지표 + 해당 경기 링크. 확정할 수 없는 원인 단정 금지 |
| 데이터 상태 | 수집 기준일·누락 수·원본 링크. 자료 미수집은 0으로 표시하지 않음 |

## 상태와 상호작용

자료를 불러오는 동안 레이아웃을 유지하는 빈 패널을 표시합니다. 자료가 없으면 이유와 현재 가능한 범위를 설명합니다. 오류가 발생하면 분석 수치를 그대로 정상처럼 보여주지 않고 재시도와 마지막 성공 시점을 제공합니다. 예정 경기에는 아직 발생하지 않은 경기 결과나 슈팅 지도를 그리지 않습니다.

카드·메뉴·필터는 키보드로 접근할 수 있어야 하고 선택된 요소의 테두리가 보여야 합니다. 마우스를 올렸을 때만 나타나는 필수 설명은 사용하지 않습니다. 상태 변화는 150~200ms로 제한하며 움직임 줄이기 설정을 따릅니다. 표는 헤더를 유지하고 휴대전화에서 핵심 열부터 보여주며 상세 열을 별도 펼침으로 제공합니다.
