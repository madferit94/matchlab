# 경기 페이지 자동 보고서

축구 예정 경기 프리뷰를 열면 `/api/report`가 서버의 경기 ID로 지표와 저장 확률을 조회합니다. 별도 문서를 업로드하거나 질문을 입력할 필요가 없습니다.

- 최종 예측과 확률은 기존 모델 값을 그대로 사용합니다. AI는 검증된 근거 ID 3~4개를 골라 보고서를 구성하고, 설명 문장은 해당 수치와 정의로 작성합니다. 자유 생성한 확률이나 새 사실은 받지 않습니다.
- 최근 5경기는 경기일 이전이면서 모델 입력 기준일 이하인 기록만 사용합니다. 이 지표 비교는 개별 모델 가중치의 기여도 분석이 아닙니다.
- 오늘부터 14일 이내 경기만 Gemini Google Search로 부상·출전 소식을 검색합니다. 출처 연결 문장, 최근 기사 날짜, 허용된 공개 매체 원문의 발행일을 확인한 항목만 표시합니다. 기사 내용의 모든 사실을 독립 검증하거나 출전 확정 명단을 확인했다는 의미는 아닙니다. 검색 내용은 확률에 반영하지 않습니다.
- AI/검색/기사 접근 실패 시 저장 지표 보고서를 유지하고 확인 불가 상태를 표시합니다. 예정 경기 배당 미수집 상태는 그대로입니다.
- 정상 결과는 서버 인스턴스 메모리와 브라우저 세션에서 최대 30분 재사용합니다. 실패 결과는 1분 캐시합니다. 서버 재시작·다른 인스턴스에서는 재생성될 수 있으므로 영구 저장은 아닙니다. 동일 요청 중복 호출은 합치고 서버 인스턴스의 동시 생성은 2개로 제한합니다.
- 기존 `GEMINI_API_KEY`, `GEMINI_MODEL` 설정을 사용합니다. 최초 생성에 AI 근거 선택 1회, 가까운 경기에는 검색 1회를 추가합니다. 검색 API 요금은 제공자 정책을 따릅니다. 별도 키를 브라우저로 보내지 않습니다.

검증: `node reports/release-0.25.0/check.cjs`, `node reports/release-0.25.0/check-browser.cjs`.
화면 소스 반영: `python reports/release-0.25.0/sync.py` (한영 진입 파일을 갱신).
실호출 기록은 `live-check.json`, 기사 날짜 대조는 `live-sources-check.json`, HTTP/모의 검사는 `checks.json`, 브라우저 검사는 `browser-checks.json`.
실제 검색 원문 응답은 공개하지 않고 로컬 `private/`에만 보존합니다. `check-live-sources.cjs`는 해당 비공개 응답이 있을 때 재검증하는 도구입니다.
