# 0.23.0 · 자연어 분석 조건 확인과 연속 질문

## 요청과 적용 범위

새 브랜치에서 축구·F1 자연어 분석 고도화. 데이터 업로드 2.0은 포함하지 않습니다.

- 입력 → 조건 확인·수정 → ‘이 조건으로 분석’ → 결과. 확인 전에는 계산 결과를 표시하지 않습니다.
- 마지막으로 성공한 분석의 조건만 이어받습니다. 취소·해석 실패·미확보 조회는 이전 조건을 새 조건으로 확정하지 않습니다.
- ‘추가해줘’, ‘작년으로 바꿔줘’, ‘최근 10경기로 변경해줘’, ‘반대로’ 등 지원 표현에서 지정하지 않은 조건을 유지합니다.
- ‘잘한 팀/선수’는 포인트·승률·순위·랩타임 등 해당 종목의 기준 선택을 먼저 제공합니다.
- ‘새 질문 시작’은 이전 조건과 결과를 초기화합니다. 새 선수·팀 추가는 최대 4개입니다.

## 축구

구단·리그·시즌·최근 경기 수·지표·장소·계산 방식·정렬을 수정합니다. 기존 6개 지표와 프리미어리그/라리가 범위 유지. 지난 시즌은 화면 기준 시즌에서 1년 이전입니다. 여러 구단 추가 시 득점/기대 득점 단일 구단 추이를 구단 비교로 전환하여 구단이 빠지지 않도록 합니다.

저장 기록 분석은 API 호출 없이 브라우저에서 계산합니다. 외부 AI 방식은 사용자가 선택합니다. API의 planOnly=true는 검증된 조건만 반환하며 계산 결과를 반환하지 않습니다. 사용자가 조건을 확인한 뒤 기존 브라우저 계산기로 실행합니다. API 키는 브라우저에 전달하지 않습니다. 기존 API 요청의 계산 계약은 유지합니다.

## F1

드라이버·지표·GP/최근 종료 GP·연도·GP 수·계산 방식·정렬을 수정합니다. 랩 범위·피트랩 제외·수치 기준·상위 N명 등 이어받은 추가 조건을 표시하고 지울 수 있습니다. 지표 변경 시 단위/조건 호환을 다시 검증합니다.

- 최근 N GP는 선택한 연도의 종료 GP 중 화면에서 선택한 GP 시각까지의 자료만 사용합니다. 예정 경기·이후 종료 경기 제외.
- GP 수가 부족하면 확보 N/요청 N을 표시합니다. 결측 지표를 0으로 바꾸지 않습니다.
- 기본 집계: 포인트·완료 랩·유효 랩·피트 진입·타이어 구간 횟수는 합계, 최고 랩타임은 최솟값, 최고 속도는 최댓값, 나머지 숫자 지표는 GP별 값의 평균. 사용자가 GP별 평균을 명시적으로 선택할 수 있습니다.
- 평균 랩타임의 기간 집계는 GP별 유효 랩 평균의 평균이며, 모든 랩을 합친 가중 평균이 아닙니다.
- 드라이버는 영문 이름을 기준으로 묶습니다. 시즌마다 바뀌는 번호를 선수 식별자로 사용하지 않습니다.
- 과거 GP 결과·다중 연도 비교는 기존 조회 경로를 유지합니다. 이 경로의 확인 화면은 조회 범위 확인용이며, 조건 수정은 새 질문으로 합니다.
- 현재 GP 예측 지표 조회 유지. 최근 GP 집계에 예측/문자 지표는 허용하지 않습니다. F1 자연어는 지원 표현과 저장 자료를 사용하는 규칙 방식입니다.
