# 0.25.3 · 팀 비교 막대 표시 수정

- 관찰: 축구 프리뷰에서 오른쪽 팀의 막대가 거의 보이지 않고 배경만 남았다.
- 원인: 오른쪽 fill이 일반 인라인 span이어서 지정한 width와 height가 적용되지 않았다. 왼쪽은 flex 자식이라 너비가 적용됐다. 새 스타일을 제거한 브라우저 검사로 원래 오류를 재현했다.
- 수정: 양쪽 fill을 block으로 표시하고 동일한 기존 눈금·계산식을 유지했다. 팀 컬러는 유지하고 배경을 중립 회색, 두께를 12px로 맞췄다. 실점에는 낮을수록 좋다는 안내를 표시했다. 모바일 최근 승무패 목록 겹침도 수정했다.
- 검증: 한글/영문 × PL/라리가 × 390/1440px의 8개 조합에서 실제 픽셀 길이와 지정 비율 차이가 1%p 이내임을 확인했다. 아스널 12, 리즈 9의 오른쪽 막대는 왼쪽의 75%다. 모바일 화면 넘침·승무패 겹침·브라우저 실행 오류가 없다.
- 저장 자료 및 모델·예측 수치는 변경하지 않았다. 이전 버전은 Git 이력에 보존했다. 참가자 확인 전.
