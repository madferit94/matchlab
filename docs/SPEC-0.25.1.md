# 0.25.1 · 분석 조건 선택 연동

## 문제와 확인한 원인
- 축구 리그를 바꿔도 전체 56개 팀과 기존 팀 선택이 남아 실행 시 거부됐다.
- 자연어에 명시한 팀이 대시보드 기본 팀으로 덮어써졌다. 전체 순위 조회 뒤 특정 팀 질문도 순위 모드로 남았다.
- F1은 기간과 관계없이 전체 드라이버·지표를 노출했다. 과거 결과 자료에 없는 랩타임도 선택할 수 있었으며, 조건 변경 후 이전 결과가 화면에 남았다.

## 수정한 동작
- 축구는 리그·시즌의 실제 완료 경기 참가 팀만 표시한다. 유효한 선택은 유지하고, 해당 범위에 없는 팀은 해제해 안내한다. 구단 미선택 시 전체 리그 순위로 계산한다.
- 질문에 명시한 팀을 우선하며, 다른 리그로 전환하면 이전 구단을 이어받지 않는다.
- Ctrl 키가 필요한 다중 선택 대신 검색 가능한 체크박스를 사용한다. 비교 대상과 지표는 최대 4개다.
- F1은 연도·GP·최근 경기 범위에 따라 드라이버와 조회 가능한 지표를 갱신한다. 종료 GP 간 변경도 지원한다. 최근 경기 모드에서는 GP 단일 선택을 비활성화한다.
- 선택했던 지표가 새 기간에 미확보이면 그대로 표시하고 이유를 안내한다. 사용자가 다른 지표를 선택하며, 임의 지표로 대체하지 않는다.
- F1 지표를 바꾸면 기존 수치·랩 조건을 해제했다고 안내한다. 다중 지표 또는 문자 지표에는 숫자 정렬을 비활성화한다.
- 조건 변경 시 이전 차트를 지우고 재실행을 안내한다. 기록 미확보와 조건 불일치를 구분한다.

## 검증
- `node analysis/release-0.25.1/check-core.cjs`: 명시한 팀 우선, 원본 점수와 계산 대조, F1 과거 포인트 대조, 시즌 첫 GP 이후 기록 제외, 전체 내장 데이터 변경 없음.
- `npm run test:analysis-ui`: 한글·영문 × 390·1440px에서 축구·F1 선택 연동, 검색, 과거 GP, 미확보 안내, 화면 넘침 및 브라우저 오류 검사.
- 저장 기록 경로는 외부 AI 호출 없이 검증한다. 실제 Gemini 응답 품질 및 제공자 장애 해결을 보장하지 않는다.
- 과거 F1의 미수집 랩 데이터는 새로 수집하지 않았다. 기존 모델과 예측 수치는 변경하지 않았다.
- 배포 화면의 참가자 확인 전.
