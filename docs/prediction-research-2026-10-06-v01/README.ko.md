# 축구 승부예측 사례와 MatchDesk 개선 방안

문서 버전: v01 · 조회일: 2026-10-06 · [English](README.en.md) · [출처와 수행 기록](sources.json)

**변수를 더 넣는 것보다 상대 수준·시간 변화·확률의 신뢰도를 먼저 검증하는 방향을 권합니다.** 아래는 논문과 공식 문서에서 확인한 사례입니다. 새 모델 학습이나 성능 개선을 실행한 보고서가 아닙니다. 현재 모델은 유지합니다.

RPS는 승·무·패 확률의 오차를 재는 값이며, 적중률이 아닙니다. 마지막 사례의 숫자는 해당 논문의 검증 평균입니다. 대회 최종 성적이나 우리 데이터의 예상 성능으로 바꾸어 말하지 않습니다. 실제 2023 대회는 예정 736경기 중 일정·개최지 변경 등을 제외한 **714경기**로 평가했습니다. [대회 주최 측 결과](https://sites.google.com/view/2023soccerpredictionchallenge/results)

## 현재 자료로 실험할 순서 — 연구 내용을 바탕으로 한 우리 제안

1. **비교 규칙부터 고정합니다.** 기존 33변수 모델, 리그 빈도 기준, 새 후보가 똑같은 경기와 시점의 자료로 예측하도록 합니다. 적중률과 함께 log loss(틀린 확신에 큰 벌점을 주는 확률 오차), Brier(확률과 실제 결과의 차이), 확률 구간별 실제 적중률을 봅니다. EPL·라리가, 시즌 첫 5경기, 이전 시즌 관측이 없는 팀, 무승부를 따로 보고 표본 수도 표시합니다.
2. **상대 수준과 최근 경기의 비중을 실험합니다.** 기존 득점·실점·xG·xGA 기록을 상대의 경기 전 강도로 조정하고, 홈·원정을 나누어 봅니다. 마지막 5경기 평균과 10경기·시간 가중 평균을 비교합니다. 반감기(오래된 경기의 영향이 절반이 되는 기간)는 학습·조정 기간에서 고릅니다. 최신 값으로 과거 경기의 상대 강도를 채우지 않습니다.
3. **독립 Poisson → Dixon–Coles를 비교합니다.** Poisson은 경기당 예상 득점으로 0골·1골·2골의 확률을 만드는 방법입니다. 팀 공격력·상대 수비력·홈 효과를 경기 전 기록으로 추정한 후, Dixon–Coles의 저득점 보정을 추가한 후보와 비교합니다. 스코어 행렬은 양수·합계 1을 검사하고, 표시 범위를 넘는 많은 득점의 확률도 보존합니다. 총 승·무·패 확률을 각 스코어 칸에서 합산합니다.
4. **시즌 초반·기록 부족 보정을 별도 비교합니다.** `현재 기록 비중 = n / (n + k)`처럼 이번 시즌 관측 경기 수 n에 따라 전 시즌·리그 평균에서 점차 현재 기록으로 이동하는 후보를 비교합니다. k는 조정 기간에서 정합니다. 이전 시즌 1부 기록이 없다는 사실을 곧바로 승격 확정으로 표시하지 않습니다. 확인된 승격 정보가 없으면 `이전 시즌 관측 없음`으로 구분합니다. 하부리그 기록이 없으면 만들어 넣지 않습니다.
5. **나무 기반 모델과 확률 보정은 그다음입니다.** 기존 모델에 대한 비교 후보로 작은 CatBoost/XGBoost를 시도하고, 조정용으로 남겨 둔 미래 구간에서 확률을 보정합니다. 보정은 “60%라고 한 경기들이 실제로 얼마나 맞는지”를 맞추는 작업입니다. temperature scaling은 가장 높은 확률의 항목을 바꾸지 않아 적중률이 그대로일 수 있습니다. [공식 확률 보정 설명](https://scikit-learn.org/stable/modules/calibration.html)

일반 무작위 분할 대신 경기 날짜로 구간을 나누어 과거에서 미래로 검증합니다. 여러 경기가 같은 날짜에 있으면 같은 묶음에 두고, 전처리·상대 평점·특징 선택·보정에 평가 구간의 정답을 쓰지 않습니다. 축구 경기 간격은 일정하지 않으므로 표본 간격이 같다는 전제의 도구 설정을 그대로 사용하지 않고 날짜 기준 구간을 정의합니다. [공식 시간순 분할의 전제](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)

## 채택 기준과 현재 한계

- 기존 평가 기록은 2025/26 760경기에서 적중률 **50.92%**, log loss **1.011080**입니다. 순위 대용값 추가 실험은 **49.87%**, **1.011412**로 개선되지 않았습니다. [기존 팩트 체크](../feature-factcheck-2026-10-06-v01/RESULTS.ko.md)
- 이미 결과를 본 2025/26·진행 시즌 기록으로 후보를 고르면 그 결과는 **탐색 비교**입니다. 새로운 독립 최종 시험이라고 부르지 않습니다. 운영 전 다음에 실제로 진행될 경기의 예측을 결과 확인 전에 고정·저장하는 방식이 필요합니다.
- 현재 자료는 2026-09-20까지의 완료 기록입니다. 이번 조사로 새 경기, 경기별 패스, 과거 선수단 가치, 2부리그, 배당 자료를 수집하지 않았습니다. Football-Data는 추가하지 않습니다. 논문에 등장하는 배당 비교는 해당 논문의 범위이며 우리의 입력 후보가 아닙니다.
- 새 후보는 확률 오차·리그별 결과·기록 부족 팀의 결과를 함께 보고 판단합니다. 전체 적중률 한 숫자만 좋아졌다고 즉시 채택하지 않습니다. 표본이 적은 구간의 차이는 불확실성을 명시합니다.
- 8비트 재생은 모형의 확률에서 추출한 **가상 경기**입니다. 한 번 뽑힌 2:1 점수를 확정 예측처럼 표시하지 않습니다. 스코어 모형을 아직 학습하지 않았으므로 이번 보고서가 현 재생의 점수 생성 방식을 검증한 것은 아닙니다.

권장 첫 실험은 **상대 강도·시간 가중치 후보와 Poisson/Dixon–Coles 후보를 나누어 비교**하는 것입니다. 시장가치 수집에 앞서 현재 자료의 시점 안전성과 확률 신뢰도를 개선할 가능성을 점검할 수 있습니다. 개선 가능성은 가설이며 성능 상승은 미확인입니다.
