# 0.25.0 경기 페이지 자동 분석 보고서

## 실행 전 설계
- 사용자 요청: 사이트 내 자동 한 장 보고서, 판단 근거와 최종 예측, 가능한 경우 부상·출전 정보 검색.
- 범위: 축구 예정 경기 프리뷰. 한영 대응. 경기 선택 시 자동 생성, 결과 재사용 및 실패 시 재시도. F1 확장은 이번 범위 아님.
- 입력: 서버의 저장 경기 ID로 조회한 지표·예측 확률. 클라이언트가 보낸 수치·문구는 신뢰하지 않음. 최근5경기는 경기일 및 모델 입력 기준일 이후 자료 제외.
- 최종 예측: 검증한 저장 확률의 최댓값(동률은 단독 선택 없음). AI는 확률이나 최종 팀을 수정할 수 없음. 지표 비교는 모델 개별 가중치 기여도라고 주장하지 않음.
- AI 역할: 검증 가능한 지표 근거를 골라 보고서 구성. 검색 정보는 별도 표시, 수치 모델에 미반영. 출처 없는 AI 부상 주장은 비노출.
- 부상 검색: Gemini Google Search 지원 여부 실호출 확인. 제공된 groundingSupports와 HTTPS 출처가 연결된 문장만 표시. 검색 확인 시점과 출처 날짜 미확인을 구분. 오래된 기사/상충/공식 출전 여부 불명은 확정하지 않음.
- 캐시: 동일 데이터·경기·언어 기준 서버 메모리 및 브라우저 세션 재사용. 서버 인스턴스 재시작 시 캐시 소실 명시. 중복 요청 병합, 병렬 실행 제한.
- 실패: 키 없음/검색 미지원/할당량/시간초과에도 저장 지표 보고서 유지. 검색 미확인을 부상 없음으로 표시하지 않음.
- 보존: 이전 버전은 Git main 및 v49에 보존, 새 기능 브랜치. API키 출력·공개 금지.

## 검증 계획
- 실제 HTTP: 유효/없는 경기, 변조 요청, 출처 없는 검색 응답, 악성 링크, 최신 날짜 필터, 키 없음, 모델 오류, 동시 중복/캐시.
- 시간 누수: 경기 이후 기록을 추가해도 최근5경기 집계 불변. 저장된 확률과 보고서 확률 동일.
- 브라우저: 한영 모바일390/데스크톱1440, 자동 표시, 경기 전환 중 이전 응답 혼입 없음, 재시도, 긴 이름/출처 줄바꿈, 키보드 접근.
- 실호출은 모의 검사와 분리 기록. 운영 배포·독립 검토·참가자 확인 여부 구분.
