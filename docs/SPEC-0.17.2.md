# MatchLab 0.17.2 / F1 0.5.2 — 느린 재생

요청: 1×도 너무 빠른 서킷 비교 재생을 수정합니다.

- 원인: 1×에서 전체 기록을 60초에 압축했습니다.
- 종료 경기의 1×는 화면 1초에 기록 시간 1초가 흐르게 변경합니다. 두 판과 선수 진행 기록은 같은 시간축을 유지합니다.
- 공통 배속: 0.25×, 0.5×, 1×(기본), 2×, 4×, 10×, 30×, 60×.
- 예정 경기는 실제 기록 시간이 없으므로 1×에서 180초 길이의 예측 연출을 사용하고 별도로 설명합니다.
- 이전 v07/0.17.1 보존, v08/사이트 v40 신규 저장. 데이터·예측 모델을 변경하지 않습니다. 참가자 확인 전입니다.

## 검증

제작자 899개, 독립 담당자 1,861개 검사 통과. 종료 16개 GP에서 화면 1초가 각 배속에 해당하는 기록 시간으로 진행되는지 제어한 실행 시각으로 확인했습니다. 두 지도 동시 갱신, 일시정지·재개·시간 이동·초기화 및 예정 7개 GP의 180초 연출도 검사했습니다. 브라우저에서는 새 배속 선택지와 기본 1×를 확인했습니다.
