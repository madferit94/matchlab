# 전체 팀 대상 학습 범위

이번 CatBoost 모델은 PL·라리가 전체 팀의 2023/24·2024/25 실제 1,518경기로 학습했습니다. 양 팀 위치를 교환한 행을 더해 입력 행은 3,036개지만 실제 경기는 1,518개입니다. 100번 반복해 학습했습니다.

승격팀 전용 모델이 아닙니다. 승격팀 보정과 리그 평균 보정은 동일한 전체 팀 모델에서 과거 기록이 부족할 때 입력값을 처리하는 두 방식입니다. 승격 초기 경기만 따로 확인한 평가는 전체 경기 평가와 구분합니다.

2025/26 전체 758경기: 승격 사례 보정 47.10%, 리그 평균 보정 48.55%. 승격 초기 27경기: 각각 44.44%, 51.85%. 승격 사례 보정의 성능 향상은 확인되지 않아 채택 보류입니다. 이 새 학습 모델은 웹에 아직 교체하지 않았습니다. 이전 학습 산출물은 보존했습니다.
