# 0.24.1 배당 입력 목적 정정

- 사용자 목적: 별도 배당 비교 서비스가 아니라 기존 승부예측의 입력에 배당 변수를 추가.
- 관찰: 0.24.0은 111지표+3배당 변수 모델과 과거 검증 화면을 추가했지만 예정 경기 예측에는 기존 모델을 유지함. 이를 전체 통합 완료라고 표현한 것은 범위를 과장함.
- 수정: 한영 사이트의 별도 확률 비교 카드·배당 안내·해당 표시 데이터 및 스타일 연결 제거. 학습 모델, 매칭 결과, 재현 코드와 기존 v48 화면은 보존.
- 아직 필요한 작업: 예정 경기의 예측 시점에 이용 가능한 배당을 확보하고 경기 ID·시각 검증 후 114개 입력 모델에 전달. 현재 과거 마감 배당은 이 용도로 대체 사용하지 않음.
- 이번 수정은 미래 배당 연결 또는 전체 예정 예측의 모델 교체가 아님. 기존 예측·득점분포·F1 데이터 보존.
- 자동 검증: 아래 실행 근거 참고. 참가자 화면 확인 전.

## 실행 근거
- 한영 완료 경기·예정 프리뷰 4경로: 비교 카드/안내/표시 데이터 없음, 기존 경기 상세 및 시뮬레이션 영역 정상, JS 오류 0.
- 첫 브라우저 검사는 외부 리소스 load 대기 제한시간 초과. 외부 리소스 요청을 차단하고 DOM 준비 기준으로 재검증하여 PASS. 외부 이미지 로딩 성공을 검증한 것은 아님.
- 기존 JSON 데이터·예측 확률 문자열 동일. F1 및 modeling/odds-0.24.0 변경 없음.
- 결합 모델 877개 확률 재현 PASS (최대차 2.22e-16), 잘못된 입력 6종 거부 PASS.
