# 0.25.2 · 질문에서 바로 결과로

## 요청과 변경
- 축구·F1의 필수 ‘분석 조건 확인’ 화면과 추가 실행 버튼을 제거한다.
- 질문 제출 → 내부 조건 검사 → 보유 기록 계산 → 차트 표시 순서로 바로 진행한다.
- 결과 위에 적용한 대상·기간·지표를 짧게 표시한다. ‘새 질문’은 이전 대화 조건과 결과를 초기화한다.
- ‘10경기로 바꿔줘’, ‘작년으로 바꿔줘’, ‘피아스트리도 추가해줘’ 같은 지원되는 후속 표현은 앞선 성공 결과의 조건을 이어받는다.
- ‘잘한 팀/선수’처럼 비교 기준이 없는 저장 기록 질문에만 지표 선택을 요청한다. 선택하면 즉시 결과를 계산한다.
- 리그와 팀 불일치, 범위를 벗어난 경기 수, 미확보 지표는 내부에서 거부하고 이전 차트를 지운다. 잘못된 질문으로 이전 성공 조건을 덮어쓰지 않는다.
- 기존 AI 분석관도 서버가 검증한 조건을 반환하면 추가 확인 없이 결과를 표시한다.
- F1 영문 연도 비교 문장(‘points in 2024 and 2025’)의 연결어를 처리한다.

## 검증 근거
- `analysis/release-0.25.2/check-browser.cjs`: 한글·영문, 390·1440px에서 축구·F1 8그룹과 모의 AI 응답 1그룹 통과.
- 필수 조건 폼 없음, 질문 즉시 표시, 리그/연도/경기 수 후속 변경, 선수 추가, 초기화, 모호한 질문, 미확보 자료, 과거 GP 비교를 확인했다.
- 가로 화면 넘침과 브라우저 실행 오류가 없었다. 작은 화면의 축구·F1 결과 캡처도 확인했다.
- 모의 AI 검사는 질문 분석 외부 요청이 1회이고 두 번째 실행 버튼 없이 결과가 표시됨을 확인했다. 실제 제공자에 호출하지 않았다.
- `check-core.cjs` 원자료 대조 6그룹, 기존 축구 계산 15항목, 서버 17항목 통과. 내장 원자료·예측 JSON은 0.25.1과 동일하다.

## 범위와 한계
- 저장 기록 분석은 지원 표현을 해석하는 방식이다. 임의의 모든 자연어를 이해한다고 보장하지 않는다.
- 실제 Gemini 키, 요금, 제공자 장애 및 응답 품질은 이번 검증 범위가 아니다. F1은 기존 저장 기록 해석 경로를 유지한다.
- 데이터 추가 수집과 예측 모델 변경은 하지 않았다. 배포 후 참가자 화면 확인은 별도다.
