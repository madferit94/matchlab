# 0.26.3 · F1 예측·실제 재생 속도 맞추기

## 요청
- 사용자: "F1 실제 영상과 예상 영상의 배속을 같게 해도 똑같이 돌지 않는다. 같은 배속이면 실제와 예측 시뮬레이션이 같은 속도로 돌게 해 달라."
- 범위: F1 GP 상세의 "서킷 위 예측 vs 실제 기록" 재생과 "경기 전 예측 vs 실제 기록" 줄 비교 탭. 예측 확률·순위·모델, 실제 기록 자료, 축구 화면은 바꾸지 않는다.
- 범위 추가(2026-10-21 팀장): 처음 설계는 서킷 재생만 다뤘으나, 줄 비교 탭도 같은 0.78 규칙이라 같은 배속에서 예측 줄이 재생 78% 지점에 먼저 도착한다. 사용자 요청("같은 배속이면 실제와 예측이 같은 속도로")을 화면 전체에서 충족하도록 줄 비교 탭에도 같은 규칙을 적용한다. 두 탭은 같은 동기화 함수 하나를 함께 쓴다.
- 담당(MatchDesk 5인): 팀장 계획·결재 → 시각화·웹(구현) → 독립 검증. 자료·모델 변경이 없어 수집·분석·예측 담당은 생략하고 기록한다. main 병합은 사용자 결재. 0.26.2(`fix/load-notice-0.26.2`) 위에 쌓는 브랜치다.

## 원인 (2026-10-21 팀장 확인)
- 두 화면은 하나의 진행값 `phase`(0~1)와 공통 배속을 쓴다. `phase`는 실제 경기 시각 구간 `timeline.start ~ timeline.start + timeline.duration`에 대응한다(`playbackDuration`).
- 실제 화면(`actualMarkers`·`recordedState`)은 그 시각의 실제 기록으로 차를 놓으므로 출발 전 대기, 세이프티카, 피트 정차가 모두 반영된다.
- 예측 화면(`predictedMarkers` → `MatchLabF1Comparison.predictedState`)은 `progress = phase / (0.78 + 0.22 × (예상순위−1)/(드라이버수−1))`, `lap_progress = progress × 총랩수`로 **시간에 비례해 일정 속도**로 움직인다. 예측 1위는 재생의 78% 지점에서 이미 결승선을 통과하고, 실제 출발 전부터 움직인다. 그래서 같은 배속이어도 예측 차가 실제보다 약 28% 빠르고 랩 수가 맞지 않는다.

## 바꾸는 것
1. **같은 경기 시계**: 실제 기록이 있는 GP에서는 예측 차의 랩 진행을 실제 경기의 선두 랩 진행에 묶는다. 어느 순간이든 **예측 1위 차의 랩 진행 = 그 시각 실제 선두 차의 랩 진행**이 되게 한다. 실제 선두가 출발 전이면 예측 차도 출발선에 있고, 실제 선두가 느려지면(세이프티카 등) 예측 차도 같이 느려지며, 실제 선두가 결승선을 통과하는 순간 예측 1위도 통과한다.
2. **예상 순위 간격**: 예측 2위 이하는 예상 순위대로 1위 뒤에 일정한 간격을 두고 따라간다. 간격은 실제 경기 흐름을 따르게 만들되(예: 순위당 고정 시간 간격을 현재 선두 랩 속도로 환산), 뒤 순위 차가 앞 순위 차를 추월하는 모습이 나오지 않아야 한다. 1위가 결승선을 통과한 뒤에도 나머지 차는 같은 속도로 결승선까지 간 뒤 멈춘다. 간격 규칙과 값을 명세 실행 결과에 적는다.
3. **예측만 있는 GP(예정 경기)**: 실제 기록이 없으므로 지금처럼 180초 연출을 유지한다. 화면 설명 문구도 그대로 둔다.
4. **설명 문구**: 실제 기록이 있는 GP의 배속 설명을 "1배속은 실제 기록 시간과 같고, 예측 차도 실제 선두의 랩 진행에 맞춰 움직입니다"처럼 쉬운 말로 바꾼다(한영).
5. 진행 막대, 시계, 드라이버 대시보드, 표, 실제 화면 차량 위치·순위는 지금과 같아야 한다. (R1 후속 팀장 결정으로 변경: 적기 정지 랩 안의 랩 재구성 차량 위치만 예외. 아래 "검증 후 수정" 참고.)
6. **줄 비교 탭**: 예측 줄도 1~5와 같은 실제 선두 시계·순위별 간격·결승 정지 규칙을 따른다. 동기화 함수는 두 탭이 공유하고(중복 구현 없음), 실제 줄·순위·시계·표는 지금과 같아야 한다. 이 탭은 종료 GP에만 있어 예정 GP 연출은 영향이 없다.

## 실행 결과 (2026-10-21)
### 원인 확인
- 위 원인 그대로 확인했다. 0.26.2에서 예측 1위는 16개 GP 모두 기록 시계의 78% 지점(예: 중국 GP 4,433초)에서 결승선을 통과했고, 실제 선두는 5,596초에 통과했다. 예측 차는 실제 경기 흐름(세이프티카·피트)과 무관하게 일정 속도였다.

### 동기화 규칙과 값
- **실제 선두 랩 진행 L(t)**: t = 진행값 × 기록 길이(초, `timeline.duration`). L(t) = `MatchLabF1Replay.timeline(race).state(t)`가 주는 실제 차량 랩 진행(`progress`) 중 가장 큰 값. 실제 화면이 차를 놓을 때 쓰는 값과 같다(랩 시작 시각 `date_start`와 `lap_duration` 사이 보간, 기록 공백에서는 직전 랩 끝에 멈춤). t<0이면 L(0), t>기록 길이면 끝 값.
- **실제 선두 결승 시각 T**: 마지막 랩(`raceLapCount`, 유효 랩 번호 최댓값)을 끝낸 가장 이른 랩 끝 시각. T 이후 L = 총랩수.
- **예측 순위 r의 랩 진행** = L(t − (r−1) × 간격). 예측 1위는 L(t) 그대로다. 같은 곡선을 늦게 따라가므로 L이 줄지 않는 한 추월이 생기지 않고, 세이프티카 때 간격(거리)이 같이 줄어든다. 1위가 결승선을 통과한 뒤에도 나머지는 1위가 달린 속도 그대로 결승선까지 가서 멈춘다.
- **간격** = min(2초, (기록 길이 − T) / (예측 차 수 − 1)). 기본 순위당 2초이고, 마지막 예측 차가 기록 끝(진행값 1)까지 결승선에 닿도록 줄인다. 16개 GP 중 13개가 2초, 아제르바이잔 1.96초, 바레인 1.39초, 영국 0.39초(실제 선두 결승 뒤 기록이 7.9초뿐).
- 상수: `SYNC_GAP_SECONDS=2`, 결승 판정 허용 오차 `SYNC_FINISH_TOLERANCE=1e-9`초(진행값 1에서 마지막 차의 부동소수 반올림 방지).
- **출발 전**: 기록 시계는 첫 유효 랩 시작에서 시작한다. 15개 GP는 1랩 시작(출발 신호), 호주 GP는 1랩 기록 시간이 없어 실제 선두의 2랩 시작이다. 그래서 진행값 0이 곧 실제 출발이며 기록 안의 "출발 전 대기" 구간은 0초다. 진행값 0에서 예측 차는 모두 L(0)(출발선)에 있고, 순위 r 차는 (r−1)×간격초 동안 출발선에 서 있다가 출발한다.
- 예정 GP(예측만 있는 GP)는 동기화 값을 넘기지 않아 0.26.2와 같은 180초·3랩 연출이다.
- **적기(검증 R1 반영)**: 아래 "검증 후 수정"의 정지 규칙을 L(t)를 만들 때 각 실제 차량의 랩 진행에 먼저 적용한다. 적기가 걸린 랩 밖에서는 위 규칙과 값이 그대로다.

  - 구현: 정지 규칙을 `redFlagHold(timeline,race)` 하나로 두고, `recordedState`(실제 쪽 진행)와 `leaderSync`(예측 시계)가 함께 쓴다. 순위·랩 번호·상태·타이어는 그대로이고 진행값(차 위치)만 바뀐다. 위치 기록이 있는 차는 지도에서 기록 좌표를 그대로 쓴다.
  - 기준 변경: "실제 화면은 0.26.2와 같다"를 "정지 랩 밖에서는 0.26.2와 같고, 정지 랩 안에서만 재구성 차량이 멈추도록 달라진다"로 바꾼다. `check-sync.cjs`는 정지 랩 밖 동일과 정지 랩 안 위치 기록 좌표 동일을 확인하고, `check_release.py`는 정지 규칙이 한 곳에만 정의되어 두 곳에서 쓰이는지 확인한다.
  - 8비트 기록 재생 탭(`replay`, `MatchLabF1Replay.mount`)은 이번 범위가 아니라 그대로다(적기 동안 계속 고르게 움직임).
- `tools/check_release.py`: 서킷 모듈의 동기화 호출 확인을 새 호출(`global.MatchLabF1Comparison.leaderSync(timeline,lapCount,predicted.length,race)`) 그대로 찾도록 바꾸고, 줄 비교 화면이 `leaderSync(recorded,null,predicted.length,race)`로 공유 시계를 만드는지도 확인한다(검증 R4 일부). 기존 확인은 그대로다.
