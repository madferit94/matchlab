# 0.11.4 · 일정 더보기 및 팀 경기 프리뷰

실행 전 요구사항: 메인 리그 일정·팀 다음 경기 모두 최초3개와 더보기 제공. 더보기는6개씩 추가하며 남은 일정이 없으면 버튼 제거. 모든 팀 다음 경기에 분석 버튼 제공. 버튼은 해당 경기 ID로 내부 프리뷰 경로를 열고 양팀 전력 비교·모델 확률·시뮬레이션을 연결한다. 최초3경기 바깥의 경기에서도 선택한 경기 유지. 주소 새로고침·한영 전환에도 선택 유지. 데이터 없는 경우 임의 생성하지 않고 안내.

범위: 저장된2026/27 PL·라리가 예정 일정, 기존 일정 기준일 유지. 외부 Understat 이동 없음. 완료 경기 분석실 경로 유지. 한영 적용, 이전0.11.3은v30/previous-0.11.3 보존. 실제 브라우저 더보기 개수 증가·팀 분석→정확한 경기 프리뷰·두 리그·영어·새로고침 확인 예정. 모델/득점분포 변경 없음. 참가자 확인 전.

- 한국어 Coventry 팀 다음 경기3→9개 확인. 네 번째 경기 분석→2026-10-31 Coventry–Sunderland, #preview=understat:31261 확인. 양팀 전력 비교·22.6/27.6/49.8 확률·득점분포·시뮬레이션 연결.
- 최초목록 바깥 선택은 카드1개를 앞에 표시(기본3+선택1), 앞 경기 모두 자동 펼치지 않음. 새로고침 및 English 전환 후에도 같은 경기·날짜 유지. 메인 더보기4→10개, 프리뷰 선택 유지.
- 라리가로 변경 시 오래된 프리뷰 주소 초기화. 영어 라리가 메인3→9개, Levante–Sevilla 2026-10-11 프리뷰/29.4·27.3·43.3 확률 확인.
