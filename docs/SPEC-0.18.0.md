# MatchLab 0.18.0 / F1 0.6.0 — 드라이버 지표와 설명

요청: 축구 화면처럼 F1 지표를 보여주고, 클릭하면 의미를 설명하며 글자가 박스 밖으로 나가지 않게 개선합니다.

- 종료 GP에 드라이버 지표 화면을 추가합니다. 선수와 지표 분류를 선택할 수 있습니다.
- 경기 결과, 랩 기록, 타이어/피트와 경기 전 예측 입력을 구분합니다. 모델을 새로 학습하거나 원본 자료를 바꾸지 않습니다.
- 지표 이름을 누르면 한글/영어 설명과 계산 범위가 말풍선으로 열립니다. 닫기 버튼, Escape, 키보드 접근과 초점 복귀를 지원합니다.
- 피트 레인 시간과 정차 시간을 구분합니다. 평균 랩·변동성의 포함 기록과 결측 처리 방법을 설명합니다. 순위 점수는 실제 순위와 다르게 모델에서 계산한 보정 점수입니다.
- 예정 GP에는 확보하지 않은 실제 결과를 생성하지 않습니다. 재생 중 지표는 기존 시점 제한을 유지합니다.
- 카드 제목은 줄바꿈, 숫자는 한 줄로 읽을 수 있게 구성합니다. 표는 필요한 경우 표 안에서만 가로 이동하며 전체 페이지 넘침을 막습니다. 중요한 글자를 숨겨서 잘라내는 방식은 사용하지 않습니다.
- 이전 v08/0.17.2는 보존하고 v09/사이트 v41에 저장합니다. 한영 README·버전·변경 이력을 갱신합니다. 이번 요청에 GitHub 전송은 포함되지 않습니다.

## 확인 근거

지표 뜻은 [OpenF1 공식 문서](https://openf1.org/docs/)와 현재 저장 자료, 원래 모델 계산식을 대조합니다. 원본 정의와 프로젝트에서 만든 요약 지표를 구분합니다.

320·375·768·1280px 및 한영 표시, 긴 지표 이름, 카드 숫자, 말풍선과 표를 실제 렌더링으로 검사합니다. 기존 사용자 탭 확인 도구 오류가 있어 별도 검증용 브라우저의 결과와 참가자의 직접 확인을 구분합니다. 참가자 확인 전입니다.
