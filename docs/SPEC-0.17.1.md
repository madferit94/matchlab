# MatchLab 0.17.1 / F1 0.5.1 — 공통 배속

요청: 예측판과 실제판을 동일한 배속으로 함께 재생합니다.

- 두 판은 하나의 재생 시점과 배속 설정(1×/2×/4×)을 공유합니다. 재생·정지·처음부터·시간 이동도 함께 적용합니다.
- 기존 예측판은 전체 재생 동안 고정 3바퀴를 이동해 실제판과 속도가 달라 보였습니다. 종료 경기에서는 기록된 전체 랩 수를 사용합니다.
- 같은 시간축을 사용해도 개별 차량의 위치와 속도는 같지 않습니다. 예측판은 예상 최종순위 연출이며 실제판은 확보한 위치·랩 기록을 사용합니다.
- 드라이버 선택·전체 차량 표시·아래 진행 기록 및 미래 기록 제외 규칙을 유지합니다.
- 기존 v06/0.17.0 보존, v07/사이트 v39 신규 저장. 새 수집·모델 재학습·GitHub 전송은 이번 범위에 포함하지 않습니다.

검증: 제작자 기능 검사, 별도 담당자 공통 시간/배속 검사 및 브라우저 확인을 기록합니다. 참가자 직접 확인 전입니다.

## 실행 근거

- 제작자 신규 검사 7,159개, 기존 선수별 진행 기록 검사 11,339개 통과.
- 독립 검사 417개 통과: 원본 보존 6개, 배속 및 동시 갱신 257개, 조립 화면 154개.
- 제어한 1초 간격에서 공통 진행 증가가 1×:2×:4× = 1:2:4임을 확인했습니다. 두 지도는 같은 진행 값으로 동시에 그려집니다.
- 브라우저에서 4× 재생 후 일시정지, 배속 유지, 실제 선수 기록 갱신을 확인했습니다. 정확한 배속 비율은 제어시간 검사 근거이며 브라우저에서 시간을 재어 측정한 결과는 아닙니다.
- 기존 1×는 전체 경기를 짧게 재생하는 압축 기준을 유지합니다. 실제 시간의 1초를 화면의 1초로 재생하는 뜻은 아닙니다.
