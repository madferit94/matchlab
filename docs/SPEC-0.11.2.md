# 0.11.2 · 공을 따라 움직이는 경기 연출

실행 전 요구사항: 각 팀 골키퍼 포함 11명 유지. 공의 순간 이동을 없애고, 패스·드리블·슈팅·득점 후 중앙 재개를 연속 경로로 연결. 선수들은 공 위치에 따라 전진·복귀·압박하고 달리는 동작을 표시. GOAL! 유지. 한국어·영어의 시뮬레이션 하단 모델명 및 점수 표본 안내 문단 전체 제거. 상단 가상 경기 설명은 유지.

기존 0.11.1은 v28/previous-0.11.1 보관. 모델 학습, 승무패 확률, 득점 분포 변경 없음. 재생·일시정지·새 시뮬레이션·움직임 줄이기 보존. 선수 수/공·선수 이동 연속성/득점 수/무득점/다득점/한영 문단 제거를 자동 검사하고 실제 브라우저 재생을 확인할 것. 실제 전술·물리 시뮬레이션이 아닌 가상 연출. 참가자 확인 전.
