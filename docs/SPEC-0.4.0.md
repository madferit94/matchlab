# MatchDesk 0.4.0 · 8비트 디자인 채택

2026-10-06 사용자가 8비트 디자인을 기본 화면으로 선택하고 GitHub 푸시·머지를 요청했습니다.

## 구현

- 기본 진입점 `index.html`은 채택된 v15 화면과 동일한 파일 내용입니다. v01~v14와 부드러운 디자인 후보는 보존합니다.
- 기존 8비트 메뉴·카드·경기장 장식을 유지합니다. 디자인 상태는 `adopted`로 기록합니다.
- 56개 팀의 로고를 각각 24×24 픽셀 격자에 원본 비율로 그려, 확대 표시할 때 픽셀 경계가 드러나도록 렌더링합니다.
- 별도 로고 이미지를 새로 그리거나 공식 마크를 교체하지 않습니다. 원본 CDN 로고를 사용하는 화면 구성 요소의 표현 방식이며 팀 이름·색·로고 정체성을 보존합니다.
- 로고 주소별로 한 번 로딩하여 화면 변경 시 재사용합니다. 화면 요소가 생성되면 자동으로 픽셀 로고를 연결합니다.
- 로고 로딩 또는 canvas(화면에 그림을 그리는 영역) 실패 시 팀 약자를 표시하며 내부 팀 링크는 계속 작동합니다.
- 픽셀 글꼴은 기존 Galmuri 2.40.3 CDN과 기본 글꼴 대체 방식을 유지합니다.

## 검증

- Node VM 40개 검사: 기존 통계·필터·말풍선·외부 링크 제거, 56개 로고 렌더링 요청과 격자 내 비율, 캐시 재사용, 이미지/그림 영역 실패 시 약자 대체, 기본 파일 동일성.
- 이미지 로딩 검사는 가짜 Image와 canvas로 실행한 코드 동작 검사입니다. 실제 56개 CDN 이미지의 픽셀 표현·브라우저 로딩을 확인한 것은 아닙니다.
- 디자인 채택은 사용자의 명시적 선택으로 확정했습니다. 실제 화면의 시각적 품질 확인은 별도이며 참가자 확인 전입니다.
- 기본 화면 자료는 v12~v14와 동일합니다. 관리자 인증·서비스 호스팅·자료 갱신·모델 개선은 추가하지 않았습니다.

## 배포 범위

GitHub 공개 저장소에 코드·문서·기본 HTML을 푸시하고 main에 머지합니다. 인터넷에서 실행되는 웹 서비스로 배포하는 작업은 포함하지 않습니다. 이전 관리 정보 분리와 모델 채택 보류 상태도 유지합니다.
