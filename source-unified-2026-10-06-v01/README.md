# Public demonstration subset / 공개 시연용 부분 자료

20 completed league fixtures and 2 forecast targets, selected from the existing normalized Understat dataset for the representative four-team report. This is **not the full historical training dataset**. No season totals are included. Source timestamps and unverified schedule times are preserved.

대표4팀 보고서를 재현하기 위한 종료20경기·미래 예측대상2경기만 포함합니다. 전체3시즌 학습자료가 아닙니다. 기본 출처는 Understat이며 원본 전체자료·StatMuse 시즌추가통계·전체사이트캐시는 로컬에 보존합니다. 예정 날짜는 변경가능, 시작시각 미확인입니다.
